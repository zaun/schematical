# SN54LS266, SN74LS266 quadruple 2-input exclusive-NOR gates with open-collector outputs

## Description

The 'LS266 is comprised of four independent 2-input exclusive-NOR gates
with open-collector outputs. The open-collector outputs permit tying
outputs together for multiple-bit comparisons.

Can Be Used as a 4-Bit Digital Comparator. Input Clamping Diodes
Simplify System Design. Fully Compatible with Most TTL Circuits.

```pins
GND: Ground
VCC: Positive supply
```

## Functional description

Positive logic: Y = !{A ⊕ B} = AB + !{A}!{B}.

Conversion note: the logic symbol (each gate) shows a 2-input
exclusive-NOR gate with inputs A and B and output Y, and the IEC logic
symbol shows the four gates with their pin numbers.

This symbol is in accordance with ANSI/IEEE Std. 91-1984 and IEC
Publication 617-12. Pin numbers shown are for D, J, N, and W packages.

Conversion note: the schematics of inputs and outputs show the
equivalent of each input, with a 12.5 kΩ NOM resistor to V~CC~, and the
typical of all outputs, an open-collector transistor.
