# SN54F04, SN74F04 hex inverters

## Description

These devices contain six independent inverters. They perform the
Boolean function Y = !{A}. [[1::2]]

The SN54F04 is characterized for operation over the full military
temperature range of –55°C to 125°C. The SN74F04 is characterized for
operation from 0°C to 70°C. [[1::3]]

## Conversion notes

- Source pages 1–3 converted; the package option addendum (p.4–6), tape
  and reel and mechanical pages (7–20) dropped, replaced by the
  generated Package and Ordering sections. The ordering lines are from
  the package option addendum.
- Dropped: the feature list, the logic symbol, the logic diagram
  (described in text), the vendor's pin drawings (J, D, N and FK
  packages).
- The source has no pin table; the pin descriptions are the
  converter's.
- The source also covers the SN54F04 (J, W and FK packages) and lists
  SN74F04DRG4 in the package option addendum (p.4–5); the catalog
  doesn't carry those parts, and the FK pinout is not drawn here. The
  SN54F04 columns of the tables are kept as the source prints them.
- The NS (SOP) package is named only in the package option addendum
  (p.5); the data sheet pages draw the J, D, N and FK packages.
- The source's switching characteristics refer to Section 1 of the
  data book for load circuits and waveforms; it isn't in the PDF, so
  there is no parameter measurement section.
- From images: overbar of Y = !{A} (p.1; the text layer reads
  "Y = A").
- Source issues: none found.
