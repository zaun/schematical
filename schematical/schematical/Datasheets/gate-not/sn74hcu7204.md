# SN74HCU7204 dual inverters

## Description

The SN74HCU7204 contains two independent unbuffered inverters. The
device performs the Boolean function Y = !{A} in positive logic. [[1::2]]

Wide Operating Voltage Range of 2 V to 6 V. Outputs Can Drive up to 10
LSTTL Loads. Unbuffered Outputs. [[1::1]]

## Pin functions


  information table (p.1) also lists SN74HCU7204PS, SN74HCU7204PSR,
  SN74HCU7204PWR and SN74HCU7204PWT; the package option addendum lists
  only SN74HCU7204PW, and the catalog carries only that part.

  only, so it has no Parameter column.

  thermal impedance of the PS and PW packages; the cells are left empty
  with a table note, because the format allows no word there.
