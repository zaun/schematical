# SN54AS1004A, SN74ALS1004, SN74AS1004A hex inverting drivers

## Description

These devices contain six independent inverting drivers. They perform
the Boolean function Y = !{A}. [[1::2]]

The SN54AS1004A is characterized for operation over the full military
temperature range of −55°C to 125°C. The SN74ALS1004 and SN74AS1004A
are characterized for operation from 0°C to 70°C. [[1::3]]

capacitance. All input pulses have the following characteristics:
PRR ≤ 1 MHz, t~r~ = t~f~ = 2 ns, duty cycle = 50%. The outputs are
measured one at a time with one transition per measurement. [[5::1]]

- Source pages 1, 2 and 5 converted. Pages 3–4 are left out: they hold
  the ratings, recommended operating conditions, electrical and
  switching characteristics of the SN54AS1004A and SN74AS1004A, whose
  parts the catalog files under another datasheet (sn74as1004a). The
  ordering lines are from the package option addendum (pp.6–8). Tape and
  reel, tube and mechanical pages (9–22) are left out; the generated
  Package section replaces them.
- Dropped: feature list (′AS1004A capacitive drive, driver version of
  ′ALS04B and ′AS04, package options), the logic symbol and the logic
  diagram (six inverters, 1A to 1Y through 6A to 6Y), and the parts of
  Figure 1 that don't apply to these totem-pole parts: the
  open-collector and 3-state load circuits, setup/hold, pulse-duration
  and enable/disable waveforms, and Notes B and C (3-state outputs).
- The page headers with the device names are not in the PDF text layer;
  the title is read from the page image (p.1).
- The absolute maximum ratings of the source are a list; each line is a
  row here. The electrical characteristics table of the source names its
  parameters by symbol only; no parameter names are added.
- The source has no pin table; the pin descriptions are the converter's.
  Page 1 draws the D, J, N and FK packages; the NS package is named only
  in the package option addendum. The J and FK packages are SN54AS1004A
  only.
- From images: overbar of Y = !{A} (p.1).
