# SN74F08 quadruple 2-input positive-AND gate

## Description

The SN74F08 contains four independent 2-input AND gates. It performs
the Boolean functions Y = A • B or Y = !{!{A} + !{B}} in positive logic.

The SN74F08 is characterized for operation from 0 °C to 70 °C.

## Pin functions

```pins
1A, 2A, 3A, 4A: Gate input A
1B, 2B, 3B, 4B: Gate input B
1Y, 2Y, 3Y, 4Y: Gate output Y
GND: Ground
VCC: Positive supply
```
