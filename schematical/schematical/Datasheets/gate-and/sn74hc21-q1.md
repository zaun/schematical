# SN74HC21-Q1 dual 4-input positive-AND gate

## Description

This device contains two independent 4-input AND gates. It performs the
Boolean function Y = A · B · C · D in positive logic. Qualified for
automotive applications. Wide operating voltage range of 2 V to 6 V;
outputs can drive up to ten LSTTL loads.
