# CDx4AC08 quadruple 2-input positive-AND gates

## Description

The 'AC08 devices are quadruple 2-input positive-AND gates. These
devices perform the Boolean function Y = A · B in positive logic. AC
types operate from 1.5 V to 5.5 V, with balanced noise immunity at 30 %
of the supply voltage, buffered inputs, balanced propagation delays and
±24 mA output drive current.

## Functional description

Logic diagram, each gate (positive logic): one 2-input AND gate, inputs
A and B, output Y.

## Parameter measurement information

C~L~ includes probe and test-fixture capacitance. All input pulses are
supplied by generators having the following characteristics:
PRR ≤ 1 MHz, Z~O~ = 50 Ω, t~r~ = 3 ns, t~f~ = 3 ns. The outputs are
measured one at a time with one input transition per measurement.
t~PLH~ and t~PHL~ are the same as t~pd~.

The load circuit also has R1 = 500 Ω from the output to switch S1
(2 × V~CC~, open or GND); S1 is open for t~PLH~ and t~PHL~, which leaves
R2 and C~L~ below. When V~CC~ = 1.5 V, R1 = R2 = 1 kΩ.

## Application information

Information in this section is not part of the TI component
specification.

Power supply: the power supply can be any voltage between the minimum
and maximum supply voltage rating located in the Section 4.1 table
([absolute maximum ratings](#absolute-maximum-ratings); Source
conflict: see Conversion notes). Each V~CC~ pin should have a good
bypass capacitor to prevent power disturbance. For devices with a
single supply, 0.1 µF is recommended. It is acceptable to parallel
multiple bypass caps to reject different frequencies of noise. A 0.1 µF
and 1 µF are commonly used in parallel. The bypass capacitor should be
installed as close to the power pin as possible for best results.

Layout: when using multiple bit logic devices inputs should not ever
float. Such input pins should not be left unconnected because the
undefined voltages at the outside connections result in undefined
operational states. All unused inputs of digital logic devices must be
connected to a high or low bias to prevent them from floating. The
logic level that must be applied to any particular unused input depends
on the function of the device. Generally they will be tied to GND or
V~CC~; whichever makes more sense or is more convenient. It is generally
acceptable to float outputs unless the part is a transceiver.
