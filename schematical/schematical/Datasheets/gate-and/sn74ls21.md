# SN54LS21, SN74LS21 dual 4-input positive-AND gates

## Description

These devices contain two independent 4-input AND gates. Each gate
performs Y = A · B · C · D or Y = !{!{A} + !{B} + !{C} + !{D}} in
positive logic.

The SN54LS21 is characterized for operation over the full military
temperature range of –55 °C to 125 °C. The SN74LS21 is characterized
for operation from 0 °C to 70 °C.
