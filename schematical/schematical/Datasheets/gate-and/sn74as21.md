# SN54ALS21A, SN54AS21, SN74ALS21A, SN74AS21 dual 4-input positive-AND gates

## Description

These devices contain two independent 4-input positive-AND gates. They
perform the Boolean functions Y = A • B • C • D or
Y = !{!{A} + !{B} + !{C} + !{D}} in positive logic.

The SN54ALS21A and SN54AS21 are characterized for operation over the
full military temperature range of –55 °C to 125 °C. The SN74ALS21A and
SN74AS21 are characterized for operation from 0 °C to 70 °C.

## Parameter measurement information

Series 54ALS/74ALS and 54AS/74AS devices. C~L~ includes probe and jig
capacitance. All input pulses have the following characteristics:
PRR ≤ 1 MHz, t~r~ = t~f~ = 2 ns, duty cycle = 50 %. Input pulses swing
from 0.3 V to 3.5 V. The outputs are measured one at a time with one
transition per measurement.
