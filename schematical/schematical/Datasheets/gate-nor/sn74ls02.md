# SN5402, SN54LS02, SN54S02, SN7402, SN74LS02, SN74S02 quadruple 2-input positive-NOR gates

## Description

These devices contain four independent 2-input-NOR gates. [[1::3]]

The SN5402, SN54LS02, and SN54S02 are characterized for operation over
the full military temperature range of –55°C to 125°C. The SN7402,
SN74LS02, and SN74S02 are characterized for operation from 0°C to 70°C. [[1::4]]

3A, 3B, GND, 4A, 4B, 4Y on pins 8 to 14); no claimed part uses it.

1Y, 2Y, 3Y, 4Y: Gate output Y
GND: Ground
VCC: Positive supply
NC: No internal connection

## Conversion notes

- Source pages 1–5 converted; the package option addendum, tape and
  reel and mechanical pages (6–27) dropped, replaced by the generated
  Package and Ordering sections. Ordering packing, temperature and
  marking columns are from the package option addendum (p.6–11).
- Pages 1–5 are scans with no text layer; every value on them was read
  from the page images (110 and 170 dpi) and checked there.
- Dropped: feature list, the logic symbol, the gate schematics (only
  described in Functional description, without resistor values).
- The source has no pin functions table; the pin descriptions are the
  converter's.
- The SN5402 and SN7402 tables are kept because the PDF covers them,
  though no SN5402 / SN7402 part is claimed here.
- The package option addendum also lists SN5402J, SN7402N, SNJ5402J,
  SNJ5402W and JM38510/… and M38510/… military parts, which this file
  doesn't claim.
- The source's "See Note 2" in the I~CCL~ rows and "see note 3" in the
  switching characteristics headings are table notes here.
- From images: overbars of Y = !{A} • !{B} and Y = !{A + B} (logic
  diagram, p.1); the description, function table and pin drawings
  (p.1); 7, 5.5, -55, 125, 0, 70, -65, 150 (absolute maximum ratings,
  p.2); 4.5, 5, 5.5, 4.75, 5.25, 2, 0.8, -0.4, 16, -12, -1.5, 2.4, 3.4,
  0.2, 0.4, 1, 40, -1.6, -20, -18, -55, 8, 14, 27, 12, 22, 15, 400
  (p.3); 0.7, 4, 8, -18, 2.5, 2.7, 0.25, 0.35, 0.5, 7, 0.1, 20, -100,
  1.6, 3.2, 2.8, 5.4, 10 (p.4); -1, -1.2, 50, -2, -40, 17, 29, 26, 45,
  280, 3.5 (p.5).
- Source issues:
  - Unconfirmed: the absolute maximum ratings (p.2) list an "Off-state
    output voltage" of 7 V; the schematics on the same page show
    totem-pole outputs. Kept as printed.
