# CD4070B, CD4077B CMOS quad exclusive-OR and exclusive-NOR gate

## Description

The Harris CD4070B contains four independent Exclusive-OR gates. The
Harris CD4077B contains four independent Exclusive-NOR gates.

The CD4070B and CD4077B provide the system designer with a means for
direct implementation of the Exclusive-OR and Exclusive-NOR functions,
respectively.

High-Voltage Types (20V Rating). Medium Speed Operation: t~PHL~,
t~PLH~ = 65ns (Typ) at V~DD~ = 10V, C~L~ = 50pF. 100% Tested for
Quiescent Current at 20V. Standardized Symmetrical Output
Characteristics. 5V, 10V and 15V Parametric Ratings. Maximum Input
Current of 1µA at 18V Over Full Package Temperature Range, 100nA at 18V
and 25°C. Noise Margin (Over Full Package Temperature Range): 1V at
V~DD~ = 5V, 2V at V~DD~ = 10V, 2.5V at V~DD~ = 15V. Meets All
Requirements of JEDEC Standard No. 13B, "Standard Specifications for
Description of 'B' Series CMOS Devices.

## Conversion notes

- Source pages 1–6 converted (the Harris data sheet). Dropped: the two
  package option addenda, tape and reel, tube and mechanical pages
  (7–33) and the notice page (34), replaced by the generated Package
  and Ordering sections.
- The PDF holds two package option addenda: one dated 15-Oct-2009
  (pp. 7–9) and one dated 18-Sep-2026 (pp. 17–19). Ordering packing,
  temperature, marking and status columns are from the later one
  (pp. 17–18).
- Dropped: the applications list, the page-1 ordering table, the pinout
  and functional diagram drawings (pinouts are generated; the gate
  equations are in the function tables) and the schematic diagrams
  (Figures 1 and 2), described in one sentence.
- Curves digitized from Figures 3–10 (pp. 5–6) to about 2 % of full
  scale. Figure 10 is drawn as straight lines on logarithmic axes; its
  10 V, C~L~ = 15 pF line is dashed in the source.
- The later package option addendum also lists JM38510/17203BCA and
  M38510/17203BCA, which the catalog doesn't carry, and no longer lists
  CD4077BPWR, which the page-1 ordering table names.
- From images: overbars of J = !{A ⊕ B}, K = !{C ⊕ D}, L = !{E ⊕ F},
  M = !{G ⊕ H} (CD4077B pinout and functional diagram, p.2).
- Source issues:
  - Source error: the note under the CD4077B truth table prints J = A ⊕ B without the bar (p.3).
  - Source error: "Input Voltage Range, All Inputs -0.5V to V~DD~ 0.5V" has no sign before 0.5V (p.4).
  - Source error: the quotation in the JEDEC Standard No. 13B feature line has no closing quotation mark (p.1); kept as printed.
