# CD4093B CMOS quad 2-input NAND Schmitt triggers

## Description

High-voltage types (20 volt rating).
CD4093B consists of four Schmitt-trigger circuits. Each circuit
functions as a two-input NAND gate with Schmitt-trigger action on both
inputs. The gate switches at different points for positive- and
negative-going signals. The difference between the positive voltage
(V~P~) and the negative voltage (V~N~) is defined as hysteresis voltage
(V~H~) (see Fig. 2). [[1::1]] [[1::2]]

Schmitt-trigger action on each input with no external components.
Hysteresis voltage typically 0.9 V at V~DD~ = 5 V and 2.3 V at
V~DD~ = 10 V. Noise immunity greater than 50%. No limit on input rise
and fall times. Standardized, symmetrical output characteristics. 100%
tested for quiescent current at 20 V. Maximum input current of 1 µA at
18 V over full package-temperature range, 100 nA at 18 V and 25°C.
5-V, 10-V, and 15-V parametric ratings. Meets all requirements of
JEDEC Standard No. 13B, "Standard Specifications for Description of
'B' Series CMOS Devices". [[1::4]]

The CD4093B types are supplied in 14-lead hermetic dual-in-line
ceramic packages (F3A suffix), 14-lead dual-in-line plastic packages
(E suffix), 14-lead small-outline packages (M, MT, M96, and NSR
suffixes), and 14-lead thin shrink small-outline packages (PW and PWR
suffixes). [[1::3]]

## Functional description

All inputs protected by CMOS protection network. Conversion note: the
logic diagram (Fig. 1, 1 of 4 Schmitt triggers) shows a 2-input NAND
gate with the hysteresis symbol followed by two buffer stages to the
output, and the protection network of an input. [[1::Figure 1]]

Conversion note: Fig. 2 (hysteresis definition, characteristic, and
test setup) shows the output V~O~ falling when the rising input V~I~
reaches V~P~ and rising when the falling input reaches V~N~, the
transfer characteristic of 1 of 4 gates, and a test setup with one
input at V~DD~ and V~I~ on the other.

```equation
V~H~ = V~P~ - V~N~
```

Conversion note: Fig. 3 (input and output characteristics) shows a
driver and a load gate, with the logic "1" input region above V~P~ and
the logic "0" input region below V~N~ set against the output regions
at V~OH~ and V~OL~.

## Application information

Conversion note: the wave shaper (Fig. 16) shows 1/4 CD4093B with a slow-edged input on pin 2, pin 1 to a control signal or V~DD~, and a square output on pin 3. Frequency range of wave shape is from DC to 1 MHz.

Conversion note: the monostable multivibrator (Fig. 17) shows R from V~DD~ and C to V~SS~ on pin 2 of 1/4 CD4093B, C discharged by a transistor of 1/3 CD4007A, pin 1 to a control signal or V~DD~, and an output pulse of width t~M~ on pin 3.

```equation
t~M~ = RC ln(V~DD~ / (V~DD~ - V~P~))
```

50 kΩ ≤ R ≤ 1 MΩ, 100 pF ≤ C ≤ 1 µF. For the range of R and C given 5 µs < t~M~ < 1 s. [[4::Figure 17]]

Conversion note: the astable multivibrator (Fig. 18) shows R from output pin 3 back to input pin 2 of 1/4 CD4093B, C from pin 2 to V~SS~, pin 1 to a control signal or V~DD~, and an output period t~A~.

```equation
t~A~ = RC ln[(V~P~ / V~N~) × ((V~DD~ - V~N~) / (V~DD~ - V~P~))]
```

50 kΩ ≤ R ≤ 1 MΩ, 100 pF ≤ C ≤ 1 µF. For the range of R and C given 2 µs < t~A~ < 0.4 s. [[4::Figure 18]]

Conversion note: Fig. 21 ("Contact Debaucer") shows a switch or relay contact to ground on the two tied inputs of a CD4093B gate, with R = 120 kΩ to V~DD~ and C of 0.001 µF to ground; the relation sign printed between C and 0.001 µF is not legible in the scan.
