# CD4093B-Q1 CMOS quad 2-input NAND Schmitt trigger

## Description

The CD4093B consists of four Schmitt-trigger circuits. Each circuit
functions as a two-input NAND gate, with Schmitt-trigger action on both
inputs. The gate switches at different points for positive- and
negative-going signals. The difference between the positive voltage
(V~P~) and the negative voltage (V~N~) is defined as hysteresis voltage
(V~H~) (see Figure 2). Source error: the hysteresis definition is
Figure 1; Figure 2 is the input and output characteristics.

The CD4093B is available in 14-lead small-outline plastic package (M96)
and 14-lead thin shrink small-outline packages (PWR suffixes).

Qualified for automotive applications. Schmitt-trigger action on each
input with no external components. Hysteresis voltage typically 0.9 V
at V~DD~ = 5 V and 2.3 V at V~DD~ = 10 V. Noise immunity greater than
50%. No limit on input rise and fall times. Standardized, symmetrical
output characteristics. 100% tested for quiescent current at 20 V.
Maximum input current of 1 µA at 18 V over full package temperature
range, 100 nA at 18 V and 25°C.

5-V, 10-V, and 15-V parametric ratings. ESD protection level per AEC-Q100 classification: 2000-V (H2)
human-body model, 200-V (M3) machine-model, 1000-V (C5) charge-device
model.

## Functional description

Conversion note: the logic diagram shows a 2-input NAND gate with the
hysteresis symbol followed by two buffer stages to the output, and the
protection network of an input, marked "All inputs protected by CMOS
protection network".

Conversion note: Figure 1 (hysteresis definition, characteristic, and
test setup) shows the output V~O~ falling when the rising input V~I~
reaches V~P~ and rising when the falling input reaches V~N~, the
transfer characteristic of 1 of 4 gates, and a test setup with one
input at V~DD~ and V~I~ on the other.

```equation
V~H~ = V~P~ - V~N~
```

Conversion note: Figure 2 (input and output characteristics) shows a
driver and a load gate, with the logic "1" input region above V~P~ and
the logic "0" input region below V~N~ set against the output regions
at V~OH~ and V~OL~.

## Application information

Conversion note: the wave shaper (Figure 15) shows 1/4 of the CD4093B-Q1 with a slow-edged input on pin 2, pin 1 to a control signal or V~DD~, and a square output on pin 3, marked "Frequency range of wave shape is from DC to 1 MHz".

Conversion note: the monostable multivibrator (Figure 16) shows R from V~DD~ and C to V~SS~ on pin 2 of 1/4 of the CD4093B-Q1, C discharged by a transistor of 1/3 CD4007A, pin 1 to a control signal or V~DD~, and an output pulse of width t~M~ on pin 3.

```equation
t~M~ = RC ln(V~DD~ / (V~DD~ - V~P~))
```

Conversion note: Figure 16 prints 50 kΩ ≤ R ≤ 1 MΩ, 100 pF ≤ C ≤ 1 µF and "for the range of R and C given 5 µs < t~M~ < 1 s".

Conversion note: the astable multivibrator (Figure 17) shows R from output pin 3 back to input pin 2 of 1/4 of the CD4093B-Q1, C from pin 2 to V~SS~, pin 1 to a control signal or V~DD~, and an output period t~A~.

```equation
t~A~ = RC ln[(V~P~ / V~N~) × ((V~DD~ - V~N~) / (V~DD~ - V~P~))]
```

50 kΩ ≤ R ≤ 1 MΩ, 100 pF ≤ C ≤ 1 µF. For the range of R and C given 2 ms < t~A~ < 0.4 s. Unconfirmed: with R of 50 kΩ and C of 100 pF, RC is far below the 2 ms lower limit printed in Figure 17.
