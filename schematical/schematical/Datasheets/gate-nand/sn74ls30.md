# SN5430, SN54LS30, SN54S30, SN7430, SN74LS30, SN74S30 8-input positive-NAND gates

## Description

These devices contain a single 8-input NAND gate. [[1::2]]

The SN5430, SN54LS30, and SN54S30 are characterized for operation over
the full military range of –55°C to 125°C. The SN7430, SN74LS30, and
SN74S30 are characterized for operation from 0°C to 70°C. [[1::3]]

another pin order (NC, A, B, V~CC~, C, D, E on pins 1 to 7 and F, G, H,
GND, Y, NC, NC on pins 8 to 14); no claimed part uses it.

## Pin functions

```pins
A, B, C, D, E, F, G, H: Gate input
Y: Gate output
GND: Ground
VCC: Positive supply
NC: No internal connection
```

## Functional description

Conversion note: the logic diagram shows one 8-input NAND gate with
inputs A to H and output Y; in positive logic
Y = !{A · B · C · D · E · F · G · H} or
Y = !{A} + !{B} + !{C} + !{D} + !{E} + !{F} + !{G} + !{H}.

Conversion note: the source also shows the logic symbol and the
schematics (each gate) of the '30, 'LS30 and 'S30, with nominal
resistor values.

## Conversion notes

- Source pages 1–5 converted; the package option addendum (pp.6–10),
  tape and reel and mechanical pages (11–24) dropped, replaced by the
  generated Package and Ordering sections. Ordering packing, temperature
  and marking columns are from the package option addendum.
- Pages 1–5 are scans with no text layer; every value and sentence on
  them was read from the page images (110 and 170 dpi) and checked
  there.
- Dropped: feature list, the vendor pinout drawings, the logic symbol
  and the gate schematics on p.2 (only mentioned in Functional
  description, without resistor values).
- The source has no pin functions table; the pin descriptions are the
  converter's.
- The SN5430 and SN7430 tables (p.3) are kept because the PDF covers
  them, though no SN5430 / SN7430 part is claimed here.
- The package option addendum also lists SN5430J, SNJ5430J, SNJ5430W
  and JM38510/… and M38510/… military parts, which this file doesn't
  claim; it lists no SN74S30 part.
- The source prints one set of absolute maximum ratings, recommended
  operating conditions, electrical and switching characteristics per
  device pair (p.3, p.4, p.5); each is its own table here.
- The absolute maximum ratings of the source print a symbol for the
  supply voltage only; no other symbol is added. The electrical
  characteristics tables of the source give symbols only, so they have
  no Parameter column.
- The † ‡ § marks, NOTE 1 and the "see note 2" of the switching
  characteristics headings are table notes here, numbered per table.
- From images: overbars of Y = !{A · B · C · D · E · F · G · H} and
  Y = !{A} + !{B} + !{C} + !{D} + !{E} + !{F} + !{G} + !{H} (positive
  logic, p.1); the description, function table and pin drawings (p.1);
  7, 5.5, -55, 125, 0, 70, -65, 150, 4.5, 5, 4.75, 5.25, 2, 0.8, -0.4,
  16, -12, -1.5, 2.4, 3.4, 0.2, 0.4, 1, 40, -1.6, -20, -18, 3, 6, 13,
  22, 8, 15, 400 (p.3); 0.7, 4, -18, 2.5, 2.7, 0.25, 0.5, 0.1, 20,
  -100, 0.35, 0.6, 1.1 (p.4); -1, -1.2, 50, -2, -40, 10, 280, 4.5, 6.5
  (p.5).
- Source issues:
  - Unconfirmed: the SN74LS30 V~OL~ rows (p.4) print no typical value
    at I~OL~ = 4 mA and a typical 0.25 V at I~OL~ = 8 mA; kept as
    printed.
