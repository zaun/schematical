# SN54ALS30A, SN54AS30, SN74ALS30A, SN74AS30 8-input positive-NAND gates

## Description

These devices contain an 8-input positive-NAND gate and perform the
following Boolean functions in positive logic:
Y = !{A • B • C • D • E • F • G • H} or
Y = !{A} + !{B} + !{C} + !{D} + !{E} + !{F} + !{G} [[1::2]]

Source error: the second function has no !{H} term, although the gate has the eight inputs A–H of the first function and of the function table (p.1 and p.2); it is kept as printed.

## Conversion notes

- Source pages 1–5 converted; the revision history (p.6), the package
  option addendum (p.7–9), tape and reel, tube and mechanical pages
  (10–25) dropped, replaced by the generated Package and Ordering
  sections. The addendum also lists JM38510 / M38510 military parts the
  catalog doesn't carry.
- Dropped: the features list, the ordering information table on p.1,
  the logic symbol and logic diagram (one 8-input NAND gate) with their
  notes, and the parts of Figure 1 that don't apply to these totem-pole
  parts: the open-collector and 3-state load circuits, setup/hold,
  pulse-duration and enable/disable waveforms, and Notes B and C
  (3-state outputs).
- The electrical characteristics table of the source names its
  parameters by symbol only, and the device column of the tables has no
  header in the source; no parameter names are added.
- In the electrical characteristics table the V~IK~ maximum is printed
  once, in a cell that spans the 'ALS30A and 'AS30 rows.
- From images: overbars of Y = !{A • B • C • D • E • F • G • H} and Y = !{A} + !{B} + !{C} + !{D} + !{E} + !{F} + !{G} (p.1).
- Source issues:
  - Source error: the second Boolean function on p.1 has no !{H} term; kept as printed.
  - Source error: note 1 of the recommended operating conditions (p.3) prints "7°°C" for 70°C; kept as printed.
  - Source conflict: the features and the pin drawing on p.1 name a DW package for the SN74ALS30A and SN74AS30; the ordering information table on p.1 and the package option addendum (p.7) list the SOIC package as D.
  - Source error: the ordering information table on p.1 prints SN74AS30AD on a row marked ALS30A, between the SN74ALS30A rows; the addendum (p.7) lists SN74ALS30AD.
  - Source error: the conditions line of the switching characteristics (p.3 and p.4) does not close its first parenthesis; kept as printed.
