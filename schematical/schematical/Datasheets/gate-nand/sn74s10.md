# SN5410, SN54LS10, SN54S10, SN7410, SN74LS10, SN74S10 triple 3-input positive-NAND gates

## Description

These devices contain three independent 3-input NAND gates. [[1::2]]

The SN5410, SN54LS10, and SN54S10 are characterized for operation over
the full military temperature range of –55°C to 125°C. The SN7410,
SN74LS10, and SN74S10 are characterized for operation from 0°C to 70°C. [[1::3]]

## Pin functions

```pins
1A, 2A, 3A: Gate input A
1B, 2B, 3B: Gate input B
1C, 2C, 3C: Gate input C
1Y, 2Y, 3Y: Gate output Y
GND: Ground
VCC: Positive supply
NC: No internal connection
```

## Conversion notes

- Source pages 1–5 converted; the package option addendum, tape and
  reel and mechanical pages (6–23) dropped, replaced by the generated
  Package and Ordering sections. Ordering packing, temperature and
  marking columns are from the package option addendum (pp.6–7).
- Pages 1–5 are scans with no text layer for their content; every value
  on them was read from the page images (110 and 170 dpi) and checked
  there.
- Dropped: feature list, the logic symbol and its footnotes, the gate
  schematics (only mentioned in Functional description, without resistor
  values).
- The source has no pin functions table; the pin descriptions are the
  converter's.
- The SN5410 and SN7410 tables are kept because the PDF covers them,
  though no SN5410 / SN7410 part is claimed here.
- The package option addendum also lists JM38510/… and M38510/…
  military parts, which the catalog doesn't carry.
- The absolute maximum ratings of the source print a symbol for the
  supply voltage only; no other symbol is added. The electrical
  characteristics tables give symbols only, so they have no Parameter
  column.
- The source's "see note 2" in the switching characteristics headings is
  a table note here.
- From images: overbars of Y = !{A · B · C} and Y = !{A} + !{B} + !{C}
  (positive logic, p.1); the description, function table and pin
  drawings (p.1); 7, 5.5, -55, 125, 0, 70, -65, 150 (absolute maximum
  ratings, p.2); 4.5, 5, 5.5, 4.75, 5.25, 2, 0.8, -0.4, 16, -12, -1.5,
  2.4, 3.4, 0.2, 0.4, 1, 40, -1.6, -20, -18, -55, 3, 6, 9, 16.5, 400,
  15, 11, 22, 7 (p.3); 0.7, 4, 8, -18, 2.5, 2.7, 0.25, 0.5, 0.1, 20,
  -100, 0.6, 1.2, 1.8, 3.3, 10 (p.4); -1, -1.2, 50, -2, -40, 7.5, 12,
  27, 280 (p.5).
