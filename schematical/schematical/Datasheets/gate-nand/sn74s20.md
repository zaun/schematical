# SN5420, SN54LS20, SN54S20, SN7420, SN74LS20, SN74S20 dual 4-input positive-NAND gates

## Description

These devices contain two independent 4-input NAND gates. [[1::2]]

The SN5420, SN54LS20, and SN54S20 are characterized for operation over
the full military range of –55°C to 125°C. The SN7420, SN74LS20, and
SN74S20 are characterized for opertion from 0°C to 70°C. [[1::4]]

2D, 2Y, GND, 1B, 1C, 1D on pins 8 to 14); no claimed part uses it.

```pins

1D, 2D: Gate input D
1Y, 2Y: Gate output Y
GND: Ground
VCC: Positive supply
NC: No internal connection
```

## Conversion notes

- Source pages 1–5 converted; the package option addendum, tape and
  reel and mechanical pages (6–24) dropped, replaced by the generated
  Package and Ordering sections. Ordering packing, temperature and
  marking columns are from the package option addendum (pp.6–9).
- Pages 1–5 are scans with no text layer; every value on them was read
  from the page images (110, 150 and 300 dpi) and checked there.
- Dropped: feature list, the logic symbol and its footnotes, the gate
  schematics (only mentioned in Functional description, without resistor
  values).
- The source has no pin functions table; the pin descriptions are the
  converter's.
- The SN5420 and SN7420 tables are kept because the PDF covers them,
  though no SN5420 / SN7420 part is claimed here.
- The package option addendum also lists JM38510/… and M38510/…
  military parts, which the catalog doesn't carry.
- The absolute maximum ratings of the source print a symbol for the
  supply voltage only; no other symbol is added. The electrical
  characteristics tables give symbols only, so they have no Parameter
  column.
- The source's "see note 2" in the switching characteristics headings is
  a table note here.
- From images: the document number SDLS079 and the date (p.1); overbars
  of Y = !{A · B · C · D} and Y = !{A} + !{B} + !{C} + !{D} (logic
  diagram, p.1); the description, function table and pin drawings
  (p.1); 7, 5.5, -55, 125, 0, 70, -65, 150 (absolute maximum ratings,
  p.2); 4.5, 5, 5.5, 4.75, 5.25, 2, 0.8, -0.4, 16, -12, -1.5, 2.4, 3.4,
  0.2, 0.4, 1, 40, -1.6, -20, -18, -55, 4, 6, 11, 400, 15, 12, 22, 8
  (p.3); 0.7, -18, 2.5, 2.7, 0.25, 0.5, 0.1, 20, -100, 1.2, 2.2, 9, 10
  (p.4); -1, -1.2, 50, -2, -40, 18, 280, 3 (p.5).
- Source issues:
  - Source error: the description (p.1) prints "opertion" for
    "operation" in its last sentence; kept as printed.
