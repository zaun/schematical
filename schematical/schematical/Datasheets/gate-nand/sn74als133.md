# SN54ALS133, SN74ALS133 13-input positive-NAND gates

## Description

These devices contain a 13-input positive-NAND gate. They perform the
following Boolean functions in positive logic:

```equation
Y = !{A • B • C • D • E • F • G • H • I • J • K • L • M}
Y = !{A} + !{B} + !{C} + !{D} + !{E} + !{F} + !{G} + !{H} + !{I} + !{J} + !{K} + !{L} + !{M}
```

The SN54ALS133 is characterized for operation over the full military
temperature range of –55°C to 125°C. The SN74ALS133 is characterized for
operation from 0°C to 70°C.
