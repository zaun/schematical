# SN74LVC1G332 single 3-input positive-OR gate

## Description

The SN74LVC1G332 device performs the Boolean function Y = A + B + C or
Y = !{!{A} • !{B} • !{C}} in positive logic.

NanoStar™ and NanoFree™ package technology is a major breakthrough in IC
packaging concepts, using the die as the package.

This device is fully specified for partial-power-down applications using
I~off~. The I~off~ circuitry disables the outputs, preventing damaging
current backflow through the device when it is powered down.

Supports 5-V V~CC~ Operation. Inputs Accept Voltages to 5.5 V. Supports
Down Translation to V~CC~. Max t~pd~ of 4.5 ns at 3.3 V. Low Power
Consumption, 10-µA Max I~CC~. ±24-mA Output Drive at 3.3 V. I~off~
Supports Live Insertion, Partial-Power-Down Mode, and Back-Drive
Protection. Latch-Up Performance Exceeds 100 mA Per JESD 78, Class II.

  reel (11–14), mechanical pages (15–33) and the notice page (34) are
  left out; the generated

- Dropped: the vendor pinout drawings, the ESD caution, the logic
  diagram (described in one sentence), the ESD protection feature line
  and the NanoStar and NanoFree packages feature line. The other
  features are sentences in Description.
- The source has no pin functions table; the pin descriptions are
  written from the pin names and the function table.
- The package option addendum also lists SN74LVC1G332DRLR and
  SN74LVC1G332DRLRG4 (DRL package), which the catalog does not carry;
  the datasheet pages give no DRL pinout.
- The electrical characteristics table of the source gives symbols only,
  so its Parameter cells are empty except for I~I~.
- The load circuits are drawn with the shared R~L~ ∥ C~L~ figure; the
  second R~L~ and S1 are described in text.
- The package thermal impedance (absolute maximum ratings) is given for
  the DBV, DCK and YEP or YZP packages only; the source gives none for
  the DRY and DSF packages.
- From images: Y = A + B + C and the overbars of
  Y = !{!{A} • !{B} • !{C}} (p.1; the text layer prints
  "Y + A ) B ) C or Y + A • B • C").
- From images: ≤2 ns, ≤2.5 ns, 1 MΩ, 1 kΩ, 500 Ω, 50 Ω and V~Δ~ in the
  Figure 1 and Figure 2 tables and notes (pp.6–7; the text layer has
  other glyphs).
- Source issues:
  - Unconfirmed: the input transition rise or fall rate at
    V~CC~ = 5 V ± 0.5 V is 10 ns/V, the same as at 3.3 V ± 0.3 V (p.3).
