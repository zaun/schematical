# SN5432, SN54LS32, SN54S32, SN7432, SN74LS32, SN74S32 quadruple 2-input positive-OR gates

## Description

These devices contain four independent 2-input OR gates.

The SN5432, SN54LS32 and SN54S32 are characterized for operation over
the full military range of –55°C to 125°C. The SN7432, SN74LS32 and
SN74S32 are characterized for operation from 0°C to 70°C.

```pins
NC: No internal connection
```

## Functional description

Conversion note: the logic diagram (positive logic) shows four 2-input
OR gates, with Y = A + B or Y = !{!{A} · !{B}}.

Conversion note: the source also shows the logic symbol and the
schematics (each gate) of the '32, 'LS32 and 'S32, with nominal resistor

## Conversion notes

- Source pages 1–5 converted; the package option addendum (pp.6–12),
  tape and reel and tube pages (13–16) and mechanical and notice pages
  (17–30) dropped, replaced by the generated Package and Ordering
  sections. Ordering packing, temperature and marking columns are from
  the package option addendum.
- Pages 1–5 are scans with no text layer; every value on them was read
  from the page images (200 dpi) and checked there.
- Dropped: feature list, the vendor pinout drawings, the logic symbol
  and the gate schematics (only described in Functional description,
  without resistor values).
- The absolute maximum ratings are a list in the source; it prints the
  symbol V~CC~ only, so the other Symbol cells are empty.
- The source's "See Note 2" in the I~CCH~ test conditions is note [4]
  of the electrical characteristics tables; its "(see note 3)" is note
  [1] of the switching characteristics tables.
- The SN5432 and SN7432 tables are kept because the PDF covers them,
  though no SN5432 / SN7432 part is claimed here.
- The package option addendum also lists SN5432J, SN7432N, SN7432NE4,
  SNJ5432J, SNJ5432W and 5962-…, JM38510/… and M38510/… military parts,
  which this file doesn't claim.
