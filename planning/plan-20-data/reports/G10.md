### Odd things, per device

- **'241 is three devices** because the brief splits on pin names; the
  three have identical positions and the same function: `74_241`
  (1OE/2OE, 1A1..), `74_241_G` (LS/S sheet prints the enables `1G`/`2G`),
  `74_241_CD` (CD74 sheets number bits from 0: `1A0`..`1A3`, `2Y0`..`2Y3`).
  `latch.json` (74_373/74_573) merges such sheets into one device with a
  note ("LS sheets name OE/LE as OC/C, CD74AC numbers bits from 0 (same
  pins)"); if you prefer that, the three can be merged under `74_241`
  names with no position change.
- '241 enables: 1OE active low, 2OE active **high** in every sheet. The new
  sn74lvc241a (SLVSLQ7, March 2026) pin table calls 2OE "active low"; its
  function table (p.14 Table 7-2) says high — used the function table. Same
  sheet gives VCC 1.1–3.6 V (older LVC sheets 1.65–3.6).
- 20-pin LCCC (FK) has the same numbering as the DIP for every '241 sheet,
  so FK shares `p20` (no separate lccc20 pinout needed).
- `74_241_G`: SN54 LS/S range differs (4.5–5.5 V vs SN74 4.75–5.25 V) →
  `partVcc` for prefixes `SN54` and `SNJ54`.
- `74_621`: open-collector outputs on **both** ports (not one side).
  Both enables asserted (OEAB high, OEBA low) = the bus-latch row.
- `74_3245`: controls (DIR, OE) referenced to VCCA; pin 23 NC; three GND
  pins (11, 12, 13).
- `3G34`, `2G241`: DCU/DCT/DQE share `p8`; RSE (UQFN) is rotated and is its
  own pinout `rse8`; YFP balls are lettered (A1..D1, D2..A2 = pins 1–8);
  YZP/YEP drawings give only pin numbers, same positions (gate.json 2G
  precedent). Balls listed in pin order.
- `74_8T240`: LVxT inputs take 5.5 V at any VCC; equals VCC max, so no
  `inputMax`. No typical timing printed (min/max only).
- `74_162245`: series output resistors (ABT/LVT on B outputs; LVCR,
  ALVCHR, FCT162245T on all outputs) not modeled. FCT entry uses the CT
  grade (fastest printed); CY74FCT162245**E**TPAC's E grade is not in
  cy74fct162245t (it lists T/AT/CT only); `CY-PA` = 48-pin TSSOP
  (same pinout as DGG). ABT/ABTH and LVT/LVTH have identical numbers.
- `74_162344`: each A input fans out to four B outputs. Each unit lists
  each A name four times in `"a"` (e.g. `["1A","1A","1A","1A","2A",...]`,
  `"y": ["1B1",...,"2B4"]`). **Check that the tristate model accepts a
  repeated `a` name**; if not, this device belongs in "Does not fit" (it
  needs fan-out) — I did not change the model.
- `74_164245` vs `74_164245_B`: same pinout and function table, but AVCB /
  AVCBH supply the control pins (1DIR, 2DIR, 1OE, 2OE) from VCCB, AVCA /
  AVCAH / ALVC from VCCA, so the domains differ → two devices. AVC timing
  is the 3.3 V ↔ 3.3 V row (the AVC parts have no 5 V side); ALVC is the
  3.3 V ↔ 5 V row. sn74avcbh164245 p.1 misprints pin 41 as `1BA5`
  (= 1A5).
- `74_11245`: SN74ACT11245DBLE was mapped by the census to `sn54act11`
  (SN54/74ACT11, a triple 3-input AND — wrong sheet). I placed it in
  `74_11245` by its name (DB SSOP-24, LE reel); its pdf/code
  (`sn54act11`, `DBL`) is covered by the code-only rule. Confirm or drop.
  Also 74ACT11245DBLE is listed **OBSOLETE** in scas031c / 74act11245.
- `74_16861`: OEAB and OEBA both active low; both low = "latch A and B
  (A = B)" row, as the model's both-enabled rule.
