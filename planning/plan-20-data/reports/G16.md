### Odd things, per device

- `74_07`: AC07/ACT07 give only tPLZ/tPZL for A→Y (open-drain); used rise = tPLZ, fall = tPZL (same convention as `74_16` in gate.json). LVC07A gives max only. SN74LVC07AMPWREP (EP) and the -Q1 parts use the main sn74lvc07a numbers.
- `74_620`: SN74ALS620ANS is **not in sn74als620a's packaging table** (only DW, N) and the pin drawing names only DW/N; placed on the common 20-pin pinout (code NS) because the census lists it Active — check before shipping. 5962-9075001MRA = SNJ54BCT620AJ (CDIP J, sn54bct620a p.5), family BCT; SN54 VCC range equals SN74 (4.5–5.5), so no `partVcc`. ABT gives only max at 25 °C.
- `2T45`: DDF (SOT-23-THIN, SN74AVC2T45DDFR) is not drawn in sn74avc2t45; it is listed in the same pin table family and assumed to share the 8-pin numbering. SN74LVC2T45YZPRB is not in sn74lvc2t45's packaging table (only YZPR); placed on the YZP ball pinout per the census code — check. YZP balls listed row-major. AVC and AXC parts stop at 3.6 V, so their timing is the VCCA 3.3 V / VCCB 3.3 V row; LVC and LXC use the 3.3 V → 5 V row. All are max values (no typicals printed except AVC at VCCA 1.2 V). AVCH folded into AVC, AXCH into AXC (same numbers).
- `4503B`: Harris scanned datasheet, no text layer — pinout, unit grouping (DIS A → buffers 1–4, DIS B → 5–6) and timing read from page images. Pin names DISA/DISB (printed "DIS A"/"DIS B"), D1–D6, Q1–Q6, VDD/VSS. CD4503BPWR is NRND in the PDF's table (census says Active).
- `74_16652`: 74AC16652 is a "PRODUCT PREVIEW"-marked table in the PDF; numbers used as printed. LVCH gives max only.
- `74_16827`: 74ACT16827 p.1 misprints pin 51 as "A14" (it is 1A4); its function table header says "each 8-bit section" (it is 10-bit). CY74FCT16827ETPAC/ETPACT: the E speed grade and these orderables are **not in cy74fct16827t** (it lists A/C grades and only obsolete orderables); placed on the common 56-pin pinout (TSSOP, code CY-PA), FCT timing taken from the C grade (4.2 ns max) — check.
- `74_16863`: both enables active low; the function table has no OEAB L + OEBA L row (both directions enabled) — the model's both-enabled rule applies there.
- `74_25244`: 24-pin with distributed GND/VCC (4 GND, 2 VCC). SN64BCT25244 (-40 to 85 °C) shares the SN74 pinout and numbers.
- `74_4T245`: RSV (UQFN) is a different pin order (`rsv16`); DYY (SOT-23-THIN 16) uses the standard order (sn74avc4t245 p.4 Fig 4-5). BQB packages exist in the PDFs but no BQB orderable was in the input.
- `TXU0104` / `TXU0304`: OE is active high and may be driven at either supply's level (VCC(MIN) logic); put in the VCCA domain. Recommended VCC min is 1.08 V (pin tables say 1.1 V); used 1.08. Inputs have integrated pull-downs (not modeled). TXU0104 comes only from the -Q1 PDF.

None of the parts has open-collector outputs on one side only.

‡ Select control = L: clocks can occur simultaneously; select control = H: clocks must be staggered to load both registers. Data at the bus terminals is stored on every rising clock edge regardless of the select or enable inputs. With SAB = SBA = L and OEAB = H, OEBA = L, the outputs reinforce their inputs (bus hold-by-loop). Model: `ab` = {register, clk xCLKAB rising, oe xOEAB high, select xSAB high}; `ba` = {register, clk xCLKBA rising, oe xOEBA low, select xSBA high}.
