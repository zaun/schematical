## Devices

### `1G34` (gate, `buf`)
- PDFs: sn74lvc1g34 (p.3 pins, p.5 VCC, p.7 timing), sn74lvc1g34-q1 (p.3, p.4), sn74aup1g34 (p.3, p.4, p.6).
- Families: LVC, AUP.
- Pinouts: `p5` (DBV/DCK/DRL/DPW), `p6` (DRY/DSF, NC on 1 and 5), `dsbga` (YZP 5-ball), `dsbga4` (YFP/YZV).
- Odd: YZP ball A1 is printed DNU (LVC) and N.C. (AUP). I named it `NC`, role `nc`, in both. (The existing `1G04` names it `DNU`; rename it if you want the house style.)
- LVC prints no typical tpd, so the entry uses the max at 3.3 V, 50 pF (4.1 ns).

### `74_757` (buffer, `tristate`, open-drain)
- PDFs: sn74bct757 (p.1 pins + function table, p.3), sn64bct757 (p.1, p.3), sn74as757 (p.1, p.3, p.4).
- Families: BCT (sn74bct757 + sn64bct757, same numbers), AS.
- An open-collector '241: 1OE is active low, 2OE is active high, the outputs don't invert. Disabled outputs are off (they read H through the pull-up in the table).
- plan-20-A §3.1 lists '757 under gate `buf`, but it has enables, so I made it `tristate` with `"output": "open-drain"`.
- AS has max timing only (18.5/6 ns).

### `74_861` (buffer, `transceiver`, separate-enable form)
- PDFs: sn74abt861 (p.1 pins, p.2 function table, p.3, p.5), sn74lvc861a (p.1, p.2, p.3, p.4).
- Families: ABT, LVC (LVC inputMax 5.5).
- OEAB/OEBA are active low. With both low the table says "latch A and B (A = B)", which is the '623-style bus-latch row.

### `74_2240` (buffer, `tristate`, inverting)
- PDFs: sn74abt2240a = sn54abt2240a (identical text; p.1 pins, p.2 table, p.4 VCC, p.5 timing), sn54bct2240 (p.1, p.2, p.4).
- Families: ABT, BCT.
- The SMD numbers 5962-9469701QRA (SN54ABT2240A, J) and 5962-9093901MRA (SN54BCT2240, J) are in the PDFs' packaging tables. Their family comes from the PDF (ABT and BCT respectively).
- ABT typ is from the SN74 table (3/4.1). The SN54 table gives typ 3/4.8.

### `74_2240_FCT` (buffer, `tristate`, inverting)
- PDF: cy74fct2240t (p.1 pins, p.2 table, p.3 VCC, p.5 timing).
- Family: FCT.
- Same function and pin positions as the '2240, but the pin names are its own: OEA/OEB, DA0-3/DB0-3 inputs, OA0-3/OB0-3 outputs, numbered 0-3 and in a different bit order. So it is a separate device.
- Timing is the CT grade max (4.1). The T grade is 8 and AT is 4.8.

### `74_16245` (buffer, `transceiver`)
- PDFs (22): 74ac16245, 74act16245, sn74act16245-ep, sn74abt16245a, sn74abth16245, sn74abt16245a-ep, sn74ahct16245, sn74alvch16245, sn74alvchr16245, sn74alvch16245-ep, sn74auc16245, sn74avc16245, sn74lvc16245a, sn74lvch16245a, sn74lvchr16245a, sn74lvcr16245a, sn74lvcz16245a, sn74lvt16245b, sn74lvth16245a, sn74lvth16245a-ep, sn74lvth16245a-q1, cy74fct16245t.
- Families: AC, ACT, ABT, AHCT, ALVC, AUC, AVC, LVC, LVT, FCT.
- Every PDF has the same 48-pin pinout. DIR high = A to B.
- Where variant PDFs give different numbers, the base-family PDF is used and the others are noted in the entry's note:
  - ALVC: sn74alvch16245 3 ns; ALVCHR 4.2.
  - LVC: sn74lvc16245a 4 ns; LVCR/LVCHR 4.8, LVCZ 3.7.
  - LVT: sn74lvt16245b 2.3/2.1; LVTH is the same.
- `partVcc`: SN74LVCZ* is VCC 2.7-3.6 (the other LVC PDFs say 1.65-3.6).
- AVC has no typ above 1.2 V, so the entry uses the max at 2.5 V (1.9). AUC uses the typ at 1.8 V (1.5).
- FCT timing is the CT grade max (4.1). The input also has a T part (7.0) and an E part (grade not in the PDF).

### `74_16541` (buffer, `tristate`)
- PDFs: 74act16541, sn74abt16541a, sn74ahc16541, sn74ahct16541, sn74lvch16541a, sn74lvth16541. All have the same 48-pin pinout.
- Families: ACT, ABT, AHC, AHCT, LVC, LVT.
- Each byte has two active-low enables (OE1 and OE2), and both must be low.

### `74_16543` (buffer, `registered`, latches)
- PDFs: 74act16543, sn74abt16543, sn74alvch16543, sn74lvch16543a, sn74lvt16543, sn74lvth16543, sn74lvth16543-ep. All have the same 56-pin pinout.
- Families: ACT, ABT, ALVC, LVC, LVT. LVT uses the sn74lvt16543 numbers; LVTH is 2.3/2.1.
- CE gates both the latch and the output: B drives only while CEAB and OEAB are both low. The spec has `ce` + `le` + `oe` per direction. The model must treat `ce` as also gating the output; plan-20-E calls this "'543 OEAB with CEAB".
- The cy74fct16543t pinout was not used: its only input part is obsolete.

### `74_162646` (buffer, `registered`, '646 form)
- PDF: cy74fct162646t (p.1 block diagram, p.2 pins, p.3 function table, p.4 VCC, p.6 timing).
- Family: FCT.
- Unit-level `dir` (DIR high = A to B) and `oe` (low), with `select` SAB/SBA high = stored.
- Timing is the AT grade clock-to-bus max (6.3).

### `74_29863` (buffer, `transceiver`, separate-enable form with 2 enables per direction)
- PDFs: sn74als29863 (p.1 pins + table, p.2 VCC, p.3 timing), sn74bct29863b (p.1, p.3, p.4).
- Families: ALS, BCT.
- `oeab` = [OEAB1 low, OEAB2 low] and `oeba` = [OEBA1 low, OEBA2 low]; all listed enables must be asserted.
- All four low = latch A and B.
- ALS has max timing only (8 ns at 50 pF).

### `29FCT52` (buffer, `registered`, registers with clock enables)
- PDF: cy29fct52t (p.1 pins + pin description, p.2 function tables + logic diagram, p.3 VCC, p.5 timing).
- Family: FCT.
- The id is not a `74_` one: the part is the Am2952 equivalent CY29FCT52T, named after its candidates.tsv function `29FCT52`. Its pin names (CPA/CEA/OEA, A0-7/B0-7) differ from the SN '2952 names, so it can't share a 74_2952 device. Rename it if you prefer.
- It has no `select`: there is no real-time path, and the destination always drives the stored register.
- Timing is max only (6.3 clock to A/B).

## Function tables of registered devices

### 29FCT52 (cy29fct52t p.2)

Register (A register: D = A, CP = CPA, CE = CEA; B register: D = B, CP = CPB, CE = CEB):

| D | CP | CE | Q |
|---|---|---|---|
| X | X | H | no change (hold) |
| L | ↑ | L | L (load) |
| H | ↑ | L | H (load) |

Output control (OEA drives the A register onto B; OEB drives the B register onto A):

| OE | Q | outputs |
|---|---|---|
| H | X | Z |
| L | L | L |
| L | H | H |

### 74_16543 (sn74abt16543 p.2; each 8-bit section, A to B shown; B to A uses CEBA/LEBA/OEBA)

| CEAB | LEAB | OEAB | A | B |
|---|---|---|---|---|
| H | X | X | X | Z |
| X | X | H | X | Z |
| L | H | L | X | B0 (latched value) |
| L | L | L | L | L |
| L | L | L | H | H |

Text (p.1): CEAB must be low to enter data from A or to output data from B. With CEAB low and LEAB low the latches are transparent; LEAB rising stores. With CEAB and OEAB both low, B is active and shows the A latch output.

### 74_162646 (cy74fct162646t p.3; per 8-bit unit)

| OE | DIR | CLKAB | CLKBA | SAB | SBA | A | B | Function |
|---|---|---|---|---|---|---|---|---|
| H | X | H or L | H or L | X | X | input | input | isolation |
| H | X | ↑ | ↑ | X | X | input | input | store A and B data |
| L | L | X | X | X | L | output | input | real-time B data to A bus |
| L | L | X | H or L | X | H | output | input | stored B data to A bus |
| L | H | X | X | L | X | input | output | real-time A data to B bus |
| L | H | H or L | X | H | X | input | output | stored A data to B bus |

Note 2 (p.3): input data is stored on every CLK rising edge regardless of OE/DIR. Note 3: data cannot go to the A bus and the B bus at the same time.

## Codes

The CY-* codes in the input come from the part names: CY-QC = QSOP (DBQ), CY-SOC = SOIC (DW), CY-PA = TSSOP (DGG), CY-PV = SSOP (DL). They sit in the `pinoutFor` rules next to the TI codes.
