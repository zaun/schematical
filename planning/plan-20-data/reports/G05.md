## Per device

### 74_541 (buffer / tristate, 141 parts)
- PDFs: sn74hc541 (= sn54hc541), sn74hct541 (= sn54hct541), sn74hcs541,
  sn74ac541, sn74ac541-q1, cd74ac541 (= cd74act541, cd54act541), cd74hc541
  (= cd74hct541, cd54hc541), sn74ahc541, sn74ahc541-q1, sn74ahct541
  (= sn54ahct541), sn74ahct541-q1, sn74abt541b (= sn54abt541), sn74abt541b-q1,
  sn74als541, sn74bct541a (= sn54bct541), sn74f541, sn74ls541 (scanned),
  sn74lv541a, sn74lv541a-q1, sn74lvc541a, sn74lvc541a-q1, sn74lvc541a-ep,
  sn74lvth541, cd74fct541, cy74fct541t (= cy54fct541t).
- Families: HC, HCT, HCS, AC, ACT, AHC, AHCT, ABT, ALS, BCT, F, LS, FCT, LV,
  LVC, LVT (LVTH folded).
- One pinout `p20` for every package (N, J, DW, DB, DBQ, NS, PW, DGS, DGV,
  RKS, RGY, FK — the 20-terminal FK and the VQFNs use the same 1–20 numbering).
- **Odd: pin names merged.** Positions and function are identical in every
  PDF, but the names printed differ: CD74HC/HCT541 and CD54/74AC/ACT541 print
  `OE1, A0–A7, Y0–Y7, OE2`; CY54/74FCT541T prints `OEA, D0–D7, OEB, O0–O7`;
  SN74LS541 prints `G1, G2`. I merged them under the SN names
  (`OE1, A1–A8, Y1–Y8, OE2`), as the library already does for e.g. `74_273`
  (CD74HC273 MR/D0/Q0 under SN names). If the generator wants names exactly as
  printed, split into `74_541` (SN), `74_541_CD` (A0–A7) and `74_541_CY`
  (D0–D7/O0–O7) with the same positions.
- **Odd:** cd74ac541 p.3 "Table 3-1 Pin Functions" is a copy of a '273 table
  (MR, CP, D/Q) — wrong; the figure on the same page is correct and was used.
- Two main PDFs for HC (SN/CD), HCT (SN/CD), AC (SN/CD), FCT (CD/CY): timing
  from SN74HC541, SN74HCT541, SN74AC541, CD74FCT541 (only typ). CD74AC541
  range 1.5–5.5 V vs SN74AC541 1.5–6 V → `partVcc` prefix `CD74AC541`.
  CY54FCT541T 4.5–5.5 V vs CY74 4.75–5.25 V → `partVcc` prefixes `CY54FCT541`
  and `5962-9223705`.
- LVC: -Q1/-EP PDFs give VCC 2–3.6 V; main PDF (1.65–3.6 V) used.
- Placed but **not in the PDF's packaging table** (name differs from the
  listed orderables, or package not drawn) — same '541 function and the
  standard 20-pin pinout, kept because the census lists them Active; drop
  them if you want table-only parts:
  - package listed only as the reel (tube/other variant not in table):
    SN74ABT541BDB, SN74ALS541-1DB, SN74ALS541-1NS, SN74F541NS,
    SN74AHC541NS, SN74LVC541ADB, SN74LVTH541DB, SN74LVTH541NS
  - DB package not in the sn74bct541a datasheet at all (pinout figure lists
    DW, N, NS only): SN74BCT541ADB, SN74BCT541ADBR
  - new "A"/"AT" names not in the downloaded PDFs (likely newer die
    revisions; specs may differ): SN74HC541AN, SN74HC541ANSR, SN74HC541APW,
    SN74HC541APWLE, SN74HCT541ANSR, SN74LV541ATDBR, SN74LV541ATDGVR,
    SN74LV541ATNSR, SN74LV541ATRGYR
- Military/SMD mapping (packaging-table marking): 5962-9074901MRA →
  SN54BCT541 (BCT), 5962-9223705MRA → CY54FCT541T (FCT), 5962-9471801Q2A/QRA
  → SN54ABT541 (ABT), 5962-9685801Q2A → SN54AHCT541 (AHCT), JM38510/65761BRA
  → SN54HCT541 (HCT).

### 1G37 (gate, buf, open-drain, 4 parts)
- PDFs: sn74lvc1g37, sn74lvc1g37-q1. Family LVC. Schmitt-trigger input

### 74_2543 (buffer / registered, 4 parts)
- PDF: cy74fct2543t. Family FCT. Pin names as printed (A0–A7, B0–B7).
- All six controls active low (pin description p.2). Model: per direction
  `store: latch`, `le` LEAB/LEBA low, `ce` CEAB/CEBA low, `oe` OEAB/OEBA low.
- Timing: max A→B (transparent) for the base T grade, 8.5 ns (AT 6.5, CT 5.5);
  no typ printed.
- 25 Ω series output resistors (not modeled).

### 4504B (buffer / translator, fixed direction, 7 parts)
- PDFs: cd4504b (scanned), cd4504b-ep. Family C.
- Tristate form, `oe: []`, six units of one bit in one unit (AIN..FIN →
  AOUT..FOUT). Domains: `VCC` = {AIN..FIN, SELECT}, `VDD` = {AOUT..FOUT}.
  VSS is ground.
- **Odd:** SELECT (pin 13) only picks TTL vs CMOS input thresholds — no logic
  effect; it is an input pin not used by any model key (put in the VCC
  domain). The EP PDF's figure titles contradict the main PDF on which SELECT
  level is TTL mode — irrelevant to the model.
- Supply: the recommended-conditions table gives 5–18 V without naming VCC
  separately (column header VDD); I used [5, 18] for both `vcc` and `vccB`.
  Timing 140/140 ns typ is TTL→CMOS VCC 5 V → VDD 10 V (nearest row to
  3.3↔5 V; there is no 3.3 V row).

### 74_16540 (buffer / tristate, invert, 2 units, 9 parts)
- PDFs: sn74abt16540a, sn74ahc16540, sn74ahct16540, sn74lvch16540a.
  Families ABT, AHC, AHCT, LVC (LVCH folded). Identical pinouts.

### 74_16640 (buffer / transceiver, invert, 2 units, 3 parts)
- PDF: sn74abt16640. Family ABT. DIR high = A→B, OE active low per section.

### 74_162830 (buffer / tristate, 2 units, 3 parts)
- PDFs: sn74alvch162830, sn74alvchs162830, sn74alvchs162830a. Family ALVC.
- **Odd:** 1-bit to 2-bit address driver: each input A1–A18 feeds two
  output banks (1Yn enabled by OE1, 2Yn by OE2), so the two units share the
  same `a` pin names. If the model forbids a pin in two units this device
  does not fit as-is.
- ALVCHS parts are 2.3–3.6 V (vs ALVCH 1.65–3.6 V) → `partVcc` prefixes
  `SN74ALVCHS162830`, `74ALVCHS162830`. Timing max 3.5 ns at 3.3 V (same in
  all three PDFs; no typ). 26 Ω series output resistors (not modeled).

### 74_8T9541 (buffer / tristate, 6 parts)
- PDFs: sn74lv8t9541, sn74lv8t9541-q1. Family LV. A '541 with Schmitt
  inputs and 5.5 V-tolerant inputs at any VCC (single-supply up/down
  translation) — modeled as single-supply `tristate`, not `translator`.
- No typ printed; timing is the 25 °C max at 3.3 V / 50 pF (8.3 / 11.2 ns).

## Does not fit
- 74FCT162H501ETPVC (cy74fct162h501t, CY74FCT162H501T 18-bit universal bus
  transceiver, '16501 function): each direction is a D latch (transparent
  while LEAB high) that, with LEAB low, also loads on the CLKAB rising edge —
  latch and register in the same path, which `store: latch|register` cannot
  express. Also listed OBSOLETE in that PDF's packaging table, and its part
  number is not in the table.

## Not this plan
- SN74LV574ANS (sn74lv574a): octal D flip-flop ('574), a register with no
  transceiver function — belongs to the existing `74_574` device in
  dff.json (which has no LV entry yet); also not in sn74lv574a's packaging
  table (only NSR variants).
