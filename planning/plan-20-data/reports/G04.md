# G04 report

9 device specs, 186 of 191 input orderables placed. Every placed row's
(pdf, code) is covered by a `pinoutFor` rule. I checked each pinout for
pin count and numbering, and checked that every pin name a model key uses
exists in it. I read every PDF in the group. Image-only pages (cd4502b
p.1–3, sdls190a, sn74ahc125-q1 p.3, sn74avc2t245 p.3, sn74lv8t7541 p.6)
were rendered and read as images.

### 74_647 — `buffer` / `registered` ('646 form), open-drain, 1 part (SN74LS647NT)
- PDF dl2:sdls190a (image only); family LS.
- **Open-collector outputs on both ports, A and B** (not one side only).
- Timing is clock → bus, typical 22/28 ns. Real-time A→B is 17/18 ns.
- Function table (p.2, LS646/LS647; ↑ = low-to-high):

  | G | DIR | CAB | CBA | SAB | SBA | A1–A8 | B1–B8 | Operation |
  |---|---|---|---|---|---|---|---|---|
  | X | X | ↑ | X | X | X | input | not specified | store A, B unspecified |
  | X | X | X | ↑ | X | X | not specified | input | store B, A unspecified |
  | H | X | ↑ | ↑ | X | X | input | input | store A and B data |
  | H | X | H or L | H or L | X | X | input | input | isolation, hold storage |
  | L | L | X | X | X | L | output | input | real-time B data to A bus |
  | L | L | X | H or L | X | H | output | input | stored B data to A bus |
  | L | H | X | X | L | X | input | output | real-time A data to B bus |
  | L | H | H or L | X | H | X | input | output | stored A data to B bus |

  Footnote: data inputs are always enabled; bus pins are stored on every
  rising clock edge.
- Model mapping:
  - `dir` DIR, where high means A→B; `oe` is G, active low.
  - `ab`: register, clocked by CAB rising, `select` SAB high.
  - `ba`: register, clocked by CBA rising, `select` SBA high.

## Does not fit

- **CD4502B** (4502): CD4502BM96, CD4502BNSR, CD4502BPW, and
  JM38510/17403BEA (cd4502b-mil).
  - Why: a strobed hex inverter/buffer with 3-state outputs. Besides the
    common OUTPUT DISABLE (active high → Z), it has an **INHIBIT** input
    that forces all six Q outputs to logic 0. The truth table (cd4502b
    p.1) has these rows:

    | DISABLE | INHIBIT | Dn | Qn |
    |---|---|---|---|
    | 0 | 0 | 0 | 1 |
    | 0 | 0 | 1 | 0 |
    | 0 | 1 | X | 0 |
    | 1 | X | X | Z |

    So Q = NOR(Dn, INHIBIT) with a 3-state enable. `tristate` has no
    force-low or second data input. It would need an `inhibit` control,
    or a 3-state NOR.
  - Data, in case the model is extended:
    - Pinout (p.1, 16-pin, D/N/NS/PW/J): 1 D3, 2 Q3, 3 D1, 4 DISABLE,
      5 Q1, 6 D2, 7 Q2, 8 VSS, 9 Q4, 10 D4, 11 Q5, 12 INHIBIT, 13 D5,
      14 Q6, 15 D6, 16 VDD.
    - Supply 3–18 V (p.2).
    - Typical at VDD 5 V, 50 pF: tPHL 135 ns, tPLH 190 ns, data or
      inhibit to output (p.3).
