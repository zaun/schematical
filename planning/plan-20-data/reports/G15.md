## Devices

### 74_623 — transceiver, separate enables (`oeab` OEAB high, `oeba` OEBA low), non-inverting
- PDFs: sn74abt623 (same file as sn54abt623a), sn54bct623, cd74ac623 (= cd74act623 = cd54act623), cd74fct623, sn74als623a, sn74hc623, sn74hct623, sn74ls623.
- Families: ABT, BCT, AC, ACT, FCT, ALS, HC, HCT, LS.
- Odd:
  - The CD (Harris) sheet numbers the bits A0–A7/B0–B7 on the same pins, so the device uses the TI names A1–A8/B1–B8.
  - The LS sheet names the enables GAB/GBA (same pins).
  - The FK (LCCC-20) package is numbered the same as the DIP, so it uses p20.
  - AC/ACT timing: the only typical is 4.5 ns, from the p.1 feature list. The table shows max values only.
  - LS timing comes from a scanned page (p.4).
  - SN74ALS623ANSR is "Last" in its packaging table (Last Time Buy).

### 74_640 — transceiver, DIR + OE, inverting
- PDFs: sn74hc640 (= sn54hc640), cd74hc640 (= cd74hct640), sn74abt640, sn74als640b (= sn54als640b = sn74as640), sn74bct640 (= sn54bct640), sn74ls640 (= sn54ls640).
- Families: HC, HCT, ABT, ALS, AS, BCT, LS.
- Odd:
  - The CD sheet numbers the bits from 0, and the LS sheet names OE as G (same pins).
  - The HC entry uses sn74hc640 (typ 10 ns). cd74hc640 prints typ 7 ns.
  - `partVcc`: SN54LS parts are 4.5–5.5 V, while SN74LS parts are 4.75–5.25 V. The prefixes are `SNJ54LS` and `8416101` (8416101RA).
  - SNJ54ALS640BW: no sheet in the ALS PDF draws the W package. I assumed the J pinout, as sn54bct640 p.1 draws "J OR W".

### 74_653 — registered ('652 form: CLKAB/CLKBA, SAB/SBA, OEAB high / OEBA low), inverting
- PDFs: sn74als653 (= sn54als653, SDAS066G). Family: ALS.
- **Open-collector on one side only:** the A outputs are open-collector, and the B outputs are 3-state (p.1 device table). The JSON says `"output": "push-pull"`, because the model takes only one output style. The A side really needs open-drain.
- Timing uses CLKAB→B max 30/17 ns (no typical printed).
- SN74ALS653-1NT: placed with the NT pinout, but the datasheet says "There are no -1 versions of the … SN74ALS653" (p.1), and the part is not in the packaging table. Confirm it exists before shipping it.
- SNJ54ALS653W: the W package is not drawn, so I assumed the JT pinout. It is not in the packaging table.
- The FK (28-pin) pinout is not included because no FK part is in the input. If it is added later, note that pin 26 is misprinted "SAB" and should be SBA. The FK map is: 1 NC, 2 CLKAB, 3 SAB, 4 OEAB, 5–7 A1–A3, 8 NC, 9–13 A4–A8, 14 GND, 15 NC, 16–21 B8–B3, 22 NC, 23 B2, 24 B1, 25 OEBA, 26 SBA, 27 CLKBA, 28 VCC.
- Function table (sn74als653 p.4, the 'ALS653/'651 table):

| OEAB | OEBA | CLKAB | CLKBA | SAB | SBA | A1–A8 | B1–B8 | Operation |
|---|---|---|---|---|---|---|---|---|
| L | H | H or L | H or L | X | X | Input | Input | Isolation |
| L | H | ↑ | ↑ | X | X | Input | Input | Store A and B data |
| X | H | ↑ | H or L | X | X | Input | Unspecified | Store A, hold B |
| H | H | ↑ | ↑ | X‡ | X | Input | Output | Store A in both registers |
| L | X | H or L | ↑ | X | X | Unspecified | Input | Hold A, store B |
| L | L | ↑ | ↑ | X | X‡ | Output | Input | Store B in both registers |
| L | L | X | X | X | L | Output | Input | Real-time B data to A bus |
| L | L | X | H or L | X | H | Output | Input | Stored B data to A bus |
| H | H | X | X | L | X | Input | Output | Real-time A data to B bus |
| H | H | H or L | X | H | X | Input | Output | Stored A data to B bus |
| H | L | H or L | H or L | H | H | Output | Output | Stored A to B and stored B to A |

  - Data outputs are inverted on the '653.
  - Clocks store on every rising edge, whatever the select and enable inputs are doing.
  - ‡ When select = H, the clocks must be staggered to load both registers.

### 74_827 — tristate, 10 bits, OE1 and OE2 both active low
- PDFs: sn74abt827 (= sn54abt827), sn74lvc827a, cy74fct827t.
- Families: ABT, LVC, FCT.
- Odd:
  - The FCT sheet names the pins D0–D9/Y0–Y9 (same pins).
  - FCT has two speed grades. The entry uses the AT grade (max 8 ns), and the note gives the CT grade (max 4.4 ns).
  - W (5962-9450901QKA) is in the packaging table but not drawn, so I assumed the JT pinout.
  - CY74FCT827CTQC (code `CY-QC`, empty package type) is not in the packaging table. I mapped it to p24 as the datasheet's "Q" (QSOP/DBQ) package, so the package/footprint has to come from the DBQ reel version.

### 1T17 — gate `buf`
- PDF: sn74aup1t17. Family: AUP (VCC 2.3–3.6 V).
- This is a single-supply part that translates up (1.8/2.5/3.3 V inputs, output at VCC), so it is not a dual-domain part.

### 74_4049 — gate `not` ×6
- PDF: cd74hc4049. Family: HC.
- The pinout is nonstandard: VCC is pin 1, GND pin 8, and pins 13 and 16 are NC.
- `inputMax` is 15 (DC input 0–15 V, used for level conversion).
- Typical 6 ns is at 5 V, 15 pF. The only 50 pF figure is max 17 ns at 4.5 V.

### 74_7541 — tristate, open-drain, OE1/OE2 active low
- PDFs: sn74ac7541, sn74ac7541-q1, sn74act7541, sn74act7541-q1, sn74ahc7541-q1, sn74ahct7541-q1.
- Families: AC, ACT, AHC, AHCT.
- Odd:
  - The RKS VQFN has the same numbering; its thermal pad is not a pin.
  - **AC:** the sheet prints only OE→Y timing (tPLZ 3.8 / tPZL 6.5 typ). I used those as rise/fall.
  - **AHC:** max only. A→Y tPZL is 42.6 ns at 5 V, 50 pF (17.5 ns at 15 pF). That is the printed value, but it looks odd.
  - **AHCT:** the typical comes from the –40 to 125 °C column.

### 74_24T245 — translator, six 4-bit DIR/OE sections
- PDFs: sn74avc24t245, sn74avch24t245 (AVCH folded into AVC).
- The 83-ball NMU map has G3 unpopulated and is listed row-major.
- DIR and OE are in the VCCA domain.
- Timing: VCCA = VCCB = 3.3 V row, max (the part stops at 3.6 V, so there is no 5 V row).

### TXU0204 — translator, tristate form
- PDFs: txu0204, txu0204-q1. Family: TXU.
- Two fixed-direction units: A1/A2→B1Y/B2Y and B3/B4→A3Y/A4Y, sharing one OE (active high).
- OE can be driven from either supply. I put it in the VCCA domain.
- The ROC VCC minimum is 1.08 V (the pin table says 1.1 V).
- Timing: VCCA 3.3 V → VCCB 5 V, max 8 ns.
