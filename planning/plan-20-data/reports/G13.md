### Odd things, per device

- `74_34`: RGY only. Exposed thermal pad not listed as a pin.
- `1G17`: the YZP 5-ball pinout leaves out B2 (no ball), the same as the existing `1G04`. A1 (DNU) is named `NC`. YFP and YZV share the 4-ball pinout. There is no typical LVC delay, so LVC uses the max (5.5 ns at 3.3 V).
- `3G07`: the AUP RSE (UQFN) pinout is mirrored: 1Y,3A,2Y,GND,2A,3Y,1A,VCC. It is the same order as the existing `3G14_RSE` device. Here it is a second pinout (`rse8`) in the same device, because the pin names are the same. LVC has no typical delay, so it uses the max.
- `74_6T06`: the census put it in UNCLASSIFIED. It is a hex inverter with open-drain outputs (LVxT inputs). It is written as kind `gate`, model/op `not`, and `function` "NOT", which matches the existing `74_06`. If the brief's "Buffer" function is wanted for every gate-kind part, change that one field.
- `1G125`: has only the three automotive `1P1G125Q*` orderables, which belong to the 1G125 device. Their family is **LVC** (the names do not show it). If another group writes a `1G125` from sn74lvc1g125, merge the two. The pinouts are the usual 1G125 ones (p5 DBV/DCK; p6 DRY with NC on pin 5).
- `74_11240`: the pinout drawing names DB/DW/NT only. 74AC11240PW is in the packaging table (TSSOP-24) and is assumed to use the same pinout.
- `74_16240`: all 10 PDFs use the same 48-pin pinout. The LVC entry uses sn74lvch16240a (VCC 1.65-3.6). sn74lvcz16240a gives VCC 2.7-3.6, so `partVcc` has prefix `SN74LVCZ`. ALVC and LVC have no typical delay, so they use the max.
- `74_16T245`: the AVC timing row is VCCA 3.3 V → VCCB 3.3 V, the nearest row to 3.3↔5 V because AVC tops out at 3.6 V. All delays are max. DIR/OE are in the VCCA domain, per the datasheet.
- `TXU0102`: both bits run A→B (A1→B1Y, A2→B2Y). The output pins are named `B1Y`/`B2Y` as printed. OE can be driven from either the VCCA or the VCCB logic level (VCC(MIN) circuitry); it is put in the VCCA domain. Inputs and OE have weak internal pull-downs, which are not modeled. Timing is the max at VCCA 3.3 V / VCCB 5 V.
- `74_2952`: there is no real-time path. The B outputs always show the register, so the model has no `select` key. `ce` = CLKENAB/CLKENBA, active low.
- `74_652` family split: the pin names differ between the PDFs, so per the brief there are four devices. Numbering and function are the same in all four.
  - `74_652`: CLKAB/SAB/OEAB/OEBA/SBA/CLKBA, A1-A8/B1-B8.
  - `74_652_LS`: CAB/SAB/GAB/GBA/SBA/CBA. sn74ls652 prints pin 22 as "SA" in the package drawings but SBA in the logic diagram, so it is named SBA here.
  - `74_652_CD`: CAB/CBA, OEAB/OEBA, and A0-A7/B0-B7 data pins.
  - `74_652_FCT`: CPAB/CPBA, GAB/GBA.
  
  If the generator should merge them under one set of names, they map one to one by pin number.
- `74_652` parts not in the PDF's packaging table: SN74HCT652DWE4 and SN74LVTH652DBRE4 (lead-finish variants). They were placed anyway, because the DW and DB packages are in the datasheet's package list and ordering information. 5962-8867301LA = SNJ54ALS652JT (marking in the sn54als652 addendum), family ALS.
- `74_652`: ALS and AS have no typical delay, so they use the max. HCT has no 5 V column; it uses the typical at 4.5 V.
- `74_652_CD`: the scanned Harris sheet has no typical in its switching tables, so both families use the max (5 V, -40 to 85 C). The input gives code `M` for CD74AC652M96 and `DW` for CD74ACT652M96; both map to `p24`.
- `74_652_FCT`: one FCT timing entry, from the base T grade (max 9 ns). The AT and CT grades are faster (6.3 and 5.7 ns). CY74FCT652TQCT is in the ordering table (p.2) but not in the packaging addendum; it was placed (DBQ).
- Part families for names that do not show one: 1P1G125Q* → LVC; CAVC16T245* → AVC; CLVC16T245M*EP and CLVCH16T245M*EP → LVC; 5962-8867301LA → ALS; CY74FCT652* → FCT; CD74AC652M96 → AC; CD74ACT652M96 → ACT.

## Function tables of registered devices

### 74_2952 (sn74abt2952a p.2; sn74lvc2952a p.2 and sn74lvth2952 p.2 identical)

A-to-B shown. B-to-A is the same using CLKENBA, CLKBA and OEBA. B0 = the level of B before the inputs were set (the register holds).

| CLKENAB | CLKAB | OEAB | A | B |
|---|---|---|---|---|
| H | X | L | X | B0 |
| X | H or L | L | X | B0 |
| L | ↑ | L | L | L |
| L | ↑ | L | H | H |
| X | X | H | X | Z |

Model: `ab` = register, clk CLKAB rising, ce CLKENAB low, oe OEAB low, no select (always stored). `ba` is the same with CLKBA/CLKENBA/OEBA.

### 74_652 (sn74abt652a p.2; same in sn74als652a p.2, sn74hct652 p.2, sn74lvth652 p.2, sn74bct652, sn74lvc652a)

| OEAB | OEBA | CLKAB | CLKBA | SAB | SBA | A1–A8 | B1–B8 | Operation |
|---|---|---|---|---|---|---|---|---|
| L | H | H or L | H or L | X | X | Input | Input | Isolation |
| L | H | ↑ | ↑ | X | X | Input | Input | Store A and B data |
| X | H | ↑ | H or L | X | X | Input | Unspecified | Store A, hold B |
| H | H | ↑ | ↑ | X‡ | X | Input | Output | Store A in both registers |
| L | X | H or L | ↑ | X | X | Unspecified | Input | Hold A, store B |
| L | L | ↑ | ↑ | X | X‡ | Output | Input | Store B in both registers |
| L | L | X | X | X | L | Output | Input | Real-time B data to A bus |
| L | L | X | H or L | X | H | Output | Input | Stored B data to A bus |
| H | H | X | X | L | X | Input | Output | Real-time A data to B bus |
| H | H | H or L | X | H | X | Input | Output | Stored A data to B bus |
| H | L | H or L | H or L | H | H | Output | Output | Stored A to B bus and stored B to A bus |

‡ Select = L: clocks can occur simultaneously. Select = H: clocks must be staggered to load both registers. Data at the bus pins is stored on every rising clock edge, whatever the enable and select levels are. With SAB/SBA in real-time mode and both OEAB and OEBA enabled, each output reinforces its input (bus hold).

Model: `ab` = register, clk CLKAB rising, oe OEAB **high**, select SAB high (stored). `ba` = register, clk CLKBA rising, oe OEBA **low**, select SBA high.
