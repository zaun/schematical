# G06 report — plan-20 buffers/transceivers

Input: 178 orderables. Placed 175 in 12 devices; 3 not placed (scan-test or register parts, see below).

## Devices

### 74_126 (tristate, 4 units, OE active high, 105 parts)
- PDFs: cd74hc126, sn74hc126, cd74hct126, sn54bct126a, sn64bct126a, sn74abt126, sn74ac126(-q1), sn74act126(-q1), sn74ahc126(-q1), sn54ahc126, sn74ahct126(-q1), sn74alvc126, sn74auc126, sn74f126, sn74hcs126(-q1), sn74ls126a, sdls044a, sn74lv126a, sn74lvc126a(-q1), sn74lvth126.
- Families: HC, HCT, BCT, ABT, AC, ACT, AHC, AHCT, ALVC, AUC, F, HCS, LS, TTL, LV, LVC, LVT (LVTH folded).
- One pinout for every package (N, D, J, DB, NS, PW, DGV, RGY, BQA, DYY). RGY/BQA thermal pad is not a pin.
- Things to know:
  - sdls044a is the same document as sn74ls126a. Its front page says SN74126 is obsolete, and SN74126N is not in its packaging table, but the census lists it as Active, so it is placed with family TTL.
  - The LS/TTL PDF names the enables 1G..4G; they are named 1OE..4OE here.
  - HC has two main PDFs. sn74hc126 is used (14 ns at 4.5 V, 50 pF); cd74hc126 gives 8 ns at 5 V, 15 pF. Both give VCC 2-6 V.
  - HCT has no typical at 50 pF, so the 15 pF typical is used.
  - ACT has no 5 V row, so the 4.5 V row is used.
  - ALVC prints no typical, so its max is used.
  - SNJ54AHC126J (J) is not in sn54ahc126's packaging table, and that PDF draws only PW/BQA. The J package uses the same 14-pin numbering, so the part is placed.
  - SN74HC126ANSR / SN74HC126APWR are census names that are not in the PDF table; they are placed under HC.

### 74_642 (transceiver, inverting, open-drain, 9 parts)
- PDFs: sn74as641 (= sn74als641a-1 = sdas300, all the same SDAS300 text), sn74ls642 (SDLS189, scanned; read from the page images).
- Families: ALS, LS.
- Open-collector outputs on **both** the A and B sides.
- LS names the enable G-bar; it is named OE here. DIR H = A->B, OE active low.
- ALS timing is max only (30/22 ns).
- Not in a packaging table, but the census says Active, so placed:
  - SN74ALS642AN and SN74ALS642A-1NE4 (N package).
  - SN74LS642-1DW (DW).
  - SN74ALS642A-1DB: the PDF draws only DW/N. DB is placed because 20-pin dual-row packages use the same numbering. Drop it if DB is not wanted without a drawing.

### 74_645 (transceiver, push-pull, 21 parts)
- PDFs: sn74as645 = sn74als645a = sn54as645 (SDAS278), sn74hc645 = sn54hc645, sn74hct645, sn74ls645 (= sn74ls642 text).
- Families: AS, ALS, HC, HCT, LS.
- FK (SNJ54HC645FK) has the same 1-20 numbering, so it shares the pinout.
- Status and packaging-table notes:
  - The SDAS278 table lists SN74ALS645A-1NSR as **NRND**; the census says Active. It is placed, so check against the Active/LTB rule.
  - SN74ALS645ADB (DB, no drawing) is placed as with the 642.
  - SN74HC645DWG4 and SN74HCT645NE4 are not in their tables but are placed.
  - SN74LS645NS is not in its table (NSR is) but is placed.

### 74_760 (tristate, 2 units of 4, OE active low, open-drain, 9 parts)
- PDFs: sn74as760 = sn74als760 = sn54as760 (SDAS141A), sn74bct760, sn74bct760-ep.
- Families: ALS, AS, BCT.
- This is the open-collector version of the '244 (plan-20-A listed '760 under gate/buf, but it has 1OE/2OE enables). It is modeled as tristate with open-drain output: OE H = output off.
- ALS and AS timing is max only.
- SN74BCT760NS has an NS package that the PDF does not draw; it is placed.

### 74_2652 (registered, 3 parts)
- PDF: cy74fct2652t. Family: FCT. Pinout q24 (QSOP-24 = DBQ); the CY-QC rows use the same pinout.
- Pin names follow the PDF (CPAB/CPBA = clocks, GAB = OEAB active high, GBA = OEBA active low, SAB/SBA = select).
- 25-ohm series output resistors.
- Timing is max for the AT grade (CT is 5.7 ns).
- The PDF ordering table lists only ATQCT and CTQCT; the ATQC and CTQC (tube) rows come from the census only.

### 74_16651 (registered, inverting, 2 units, 1 part)
- PDF: 74act16651. Family: ACT. DL SSOP-56. OEAB active high, OEBA active low.
- `invert: true` is set inside ab/ba.

### 74_162952 (registered with clock enables, 2 units, 2 parts)
- PDF: sccs065c (CY74FCT16952T/162952T/162H952T). Family: FCT (162H952 bus hold folded in, not modeled).
- The PA code is TSSOP-56 (TI DGG); pinout code in the input is "CY-PA".
- The orderables are the **E** speed grade (74FCT162H952ETPAC/-T), which the switching table does not list. The AT max (10 ns) is used; CT is 6.3 ns.
- The PDF's old addendum lists 74FCT162H952ETPAC/ETPACT as OBSOLETE, while the census says Active. Check before shipping.

### 74_4245 (translator, DIR/OE transceiver form, 6 parts)
- PDFs: sn74lvc4245a, sn74lvc4245a-ep. Family: LVC.
- VCCA = 5-V side (A port, DIR, OE); VCCB = 3.3-V side (B port).
- Pin 23 is printed "NC,VCCB" in the figure and "VCCB" in the pin table and the EP PDF, so it is VCCB here. **Two pins (23, 24) are named VCCB**, which matters if `domains.power` must name exactly one pin.
- Timing is max only.

### 74_4245_LVCC (translator, 7 parts)
- PDF: sn74lvcc4245a. Family: LVCC folded into LVC.
- Split from 74_4245 for two reasons:
  - Pin 23 is NC.
  - VCCB is 2.7-5.5 V instead of 2.7-3.6 V, and both devices would otherwise share one LVC timing entry.
- SN74LVCC4245ANS is placed (NS is drawn in the PDF).

### 1T125 (tristate, 1 unit, OE active low, 3 parts)
- PDFs: sn74lv1t125, sn74lv1t125-q1. Family: LV (as in the existing 1T gates).
- Single-supply, input-threshold translator. Not dual-supply, so no domains.

### 74_4T125 (tristate, 4 units, OE active low, 3 parts)
- PDFs: sn74lv4t125, sn74lv4t125-ep. Family: LV.

### TXU0101 (translator, tristate form, 6 parts)
- PDFs: txu0101, txu0101-q1. Family: TXU.
- Output pin is named "BY" as printed.
- OE works from either supply (VCC(MIN) logic) and is put in the VCCA domain.
- Inputs have weak pull-downs (not modeled).
- Timing is max at VCCA 3.3 V / VCCB 5 V. No inputMax because VI max 5.5 V equals VCC max.
