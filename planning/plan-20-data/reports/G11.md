### Odd things, per device

- **Split by pin names** (the brief's rule: one name set per device). The 646 is
  four devices only because the datasheets name the same pins differently:
  - `74_646`: CLKAB / CLKBA / OE, A1-A8 / B1-B8 (ABT, ALS, AS, HC, HCT, LVC, LVTH)
  - `74_646_FCT`: CPAB / CPBA / G (CY54/74FCT646T)
  - `74_646_AC`: CAB / CBA / OE, A0-A7 / B0-B7 (CD74AC646)
  - `74_646_LS`: CAB / CBA / G (SN74LS646)

  All four have the same positions, function table and model. Same for
  `74_2244_FCT` (OEA/OEB, DA0-3/OA0-3/DB0-3/OB0-3) and `74_2245_FCT` (T/R,
  A0-A7/B0-B7). G01 instead renamed FCT pins to SN74 names and merged them into one
  device (`74_244`). If the lead wants that here too, the name maps are in each note:
  - CPAB→CLKAB, CPBA→CLKBA, G→OE
  - CAB→CLKAB, CBA→CLKBA
  - An→A(n+1), Bn→B(n+1)
  - OEA→1OE, DAn→1A(n+1), OAn→1Y(n+1), OEB→2OE, DB0..3→2A4..1, OB0..3→2Y4..1
  - T/R→DIR

- **`74_638`**: the brief lists the '638 under the oeab/oeba form, but TI's
  SN74ALS638A (sdas123a p.1) is DIR + OE. It is the inverting part. **A-port outputs
  are open-collector and B-port outputs are 3-state** (one side only). I set
  `"output": "push-pull"` because the model has one output type per device. The A
  side needs open-drain if the model gains a per-side output.
- **`74_649`**: open-collector on both ports, inverting. I set `"output": "open-drain"`
  and `"invert": true`. The inversion applies to both real-time and stored data (the
  function table says "A-bar"/"B-bar" for both).
- **`74_646` ABT**: there are two main PDFs, sn74abt646a and sn74abt646. They have
  the same pinout and function, and both PDFs' parts are placed. Timing is from
  sn74abt646a.
- **`74_646` AS** comes from the same file as sn74als646a (sn74as646).
- **Timing with no typical value printed**: ALS, AS, LVC, AC, FCT, LV8T244 and
  LVC1G/2G use the max value, and each note says so.
- **FCT timing** uses the slowest speed grade (the plain T grade). The A and C grades
  are faster, and their values are in the notes.
- **FCT supply range**: CY54FCT646T is 4.5-5.5 V and CY74FCT646T is 4.75-5.25 V. This
  is a `partVcc` entry for prefix `5962-9222301` (the CY54 SMD).
- **`74_646_AC`**: the main path is "Store A data to B bus" max 12.3 ns at 5 V (p.5).
  The cover's 5.3 ns typical is the data path.
- **`74_32543`**: I read the PZ pinout from the drawing image, because the text
  extraction scrambles the top and bottom rows. 100 pins, 2 units of 18 bits.
  Timing is A→B transparent typical 3.5 ns; LE→B is 4.6/4.3 typ (in the note).
- **`40109B`**:
  - Pin names: "ENABLE A".."ENABLE D" are shortened to `ENA`..`END`.
  - Supplies: VCC (low side, pin 1), VDD (high side, pin 16), VSS ground.
  - Domains: VCC holds A-D and the enables; VDD holds E-H.
  - Supply range: only one range is printed, 3-18 V. Both `vcc` and `vccB` are [3, 18].
  - `inputMax` is 18, because inputs may exceed VCC and VDD (p.1). There is no
    `inputMaxB`, because the B side is outputs only.
  - Timing: the 5 V → 10 V L-H row (the nearest to 3.3↔5 V), typ tPLH 130 / tPHL 300.
- **`1G125`**:
  - Supply ranges: CAHCT1G125… (-Q1) has VCC 3-5.5 V and SN74LVC1G125B has
    1.1-5.5 V. Both are `partVcc` entries.
  - G13 wrote a partial `1G125` holding only the 1P1G125Q* automotive parts. Its
    pinout names p5/p6 match mine.
  - DSBGA balls are row-major: YZP has 5 balls, YFP has 6 with B2 = DNU (role nc).
- **`2G126`**: the RSE UQFN has its own numbering, in pinout `rse8`. DQE X2SON uses
  the same numbering as DCU (`p8`).
- **Packaging codes and orderables not in the PDF packaging tables.** These came from
  name matches; I placed them by package code:
  - 74ABT646ADBLE / SN74ABT646ADBLE: code `DBL`, the DB SSOP-24 pinout.
  - SN74ABT646ANS, SN74BCT2244NS, SN74BCT2245NS
  - SN74LS646NT3, SN74LS649NT
  - CY74FCT2244ATQC-TI, CTQC, TQC: code `CY-QC`, the QSOP (DBQ) pinout.
  - CY74FCT2245SOCT: code `CY-SOC`, the DW pinout.
  - SN74LVC1G125YZPRB
- **Not modeled**: series damping resistors (2244/2245/162541/25245), bus hold (ABTH,
  LVTH), Schmitt-trigger inputs (6T17).

Sources: sn74abt646a p.4, sn74als646a p.3, cy74fct646t p.2, cd74ac646 p.2,
sdls190a p.2.

| OE | DIR | CLKAB | CLKBA | SAB | SBA | A1-A8 | B1-B8 | Operation |
|---|---|---|---|---|---|---|---|---|
| X | X | ↑ | X | X | X | Input | Unspecified | Store A, B unspecified |
| X | X | X | ↑ | X | X | Unspecified | Input | Store B, A unspecified |
| H | X | ↑ | ↑ | X | X | Input | Input | Store A and B data |
| H | X | H or L | H or L | X | X | Input disabled | Input disabled | Isolation, hold storage |
| L | L | X | X | X | L | Output | Input | Real-time B data to A bus |
| L | L | X | H or L | X | H | Output | Input | Stored B data to A bus |
| L | H | X | X | L | X | Input | Output | Real-time A data to B bus |
| L | H | H or L | X | H | X | Input | Output | Stored A data to B bus |

How the table maps to the model:

- The unit has `dir` {DIR, ab: high} and `oe` {OE, low}.
- `ab` is a register clocked by CLKAB rising, with select SAB active high
  (asserted = stored).
- `ba` is a register clocked by CLKBA rising, with select SBA active high.
- Clocking stores the port whatever OE and DIR are ("data input functions are always
  enabled").
- `74_649` (sdls190a p.2, LS648/LS649 column): the same rows with complemented data
  ("Real-time A-bar data to B bus", "Stored A-bar data to B bus", and the same for B).
  Its outputs are open-collector.

### 74_32543 (each 18-bit section, sn74abth32543 p.3)

A to B is shown. B to A is the same with CEBA, LEBA and OEBA.

| CEAB | LEAB | OEAB | A | B |
|---|---|---|---|---|
| H | X | X | X | Z |
| X | X | H | X | Z |
| L | H | L | X | B0 (latched) |
| L | L | L | L | L |
| L | L | L | H | H |

From the description on p.2:

- CEAB must be low to enter data from A **and** to output data to B.
- With CEAB low, LEAB low makes the latch transparent, and LEAB low→high stores.

How the table maps to the model, for `ab` (`ba` is the same with LEBA, CEBA, OEBA):

- `store` = latch
- `le` = {nLEAB, low}
- `ce` = {nCEAB, low}
- `oe` = {nOEAB, low}

B drives only while CEAB and OEAB are both low.
