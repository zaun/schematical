# plan-78-F: App: potentiometer symbol, facts, `RV` prefix, Part Editor, exports

Last updated: 2026-11-25
Effort: large (3h–1d)
Depends on: plan-78-E

F shows potentiometers in the app. A single-gang pot draws as a resistor with a wiper arrow (a
trimmer with the trimmer mark), is numbered `RV1, RV2, …`, and its facts say resistance, taper and
turns; a dual-gang pot draws as a block, as resistor arrays do. The Part Editor edits the new keys,
and the KiCad / EasyEDA exports treat the pot like the other small two-terminal symbols. Tests run
on fixture parts in a User Library file, since G and H ship the real ones later.

## 1. Goal

On fixture parts (§ 3.6):

- A one-gang pot whose pinout names `a`, `w` and `b` uses `PartSymbol.potentiometer`: `a` left,
  `b` right, `w` at the bottom centre, a zig-zag with an arrow from `w` onto it; a `trimmer` draws
  the trimmer mark (a short bar across the zig-zag's end, no arrow head) instead. It rotates like a
  resistor. A two-gang pot, or one whose wiper pins are not all in the pinout, is a block.
- Its reference prefix is `RV` (`ReferenceCategory.potentiometer`, title "Potentiometer"), set in
  Settings ▸ Reference Defaults like the others.
- Its facts: "Resistance" (end to end), "Taper" (`Linear`, `Logarithmic`, `Reverse logarithmic`),
  "Turns" (shown only when not 1), "Gangs" (only when 2), plus the existing tolerance and power
  rows. `kindName` is "Potentiometer" (`trimmer`: "Trimmer potentiometer"; `slide`: "Slide
  potentiometer"; `thumbwheel`: "Thumbwheel potentiometer").
- The value label above the symbol is the end-to-end resistance (`ResistorValue.text`), as on a
  fixed resistor.
- The Part Editor's resistor kind has fields for `wipers` (a list of `a`, `w`, `b` pins), `pot`
  (a choice of four), `taper` (a choice of three), `turns` (a number); the drift test passes.
- KiCad and EasyEDA exports place the pot with the small-symbol body box, like a resistor.
- Every fixed resistor draws, numbers and exports exactly as before.

### Non-goals (explicit constraints)

- No knob, no wiper position, no new simulation display (owner decision).
- No change to the resistor symbol's look, the pull resistors, `GENERIC-RESISTOR`'s Ohms field,
  or the BOM grouping of fixed resistors.
- No part ships here (G, H).

## 2. Current State

`symbol(for:)` gives `PART_RESISTOR` the `.resistor` symbol only for one element with pins `1` and
`2`, else `.block` (`PartCatalog.swift:2057-2063`). `ChipLayout` lays out `.resistor` with the
capacitor's two-pin layout (`SchematicModel.swift:341`) and `.crystal` with a third pin at the
bottom centre (:797-810). `ReferenceCategory.of` maps `PART_RESISTOR` to `.resistor` (`R`). There
is no potentiometer anywhere in the app (`grep -rli potentiometer schematical/schematical` → no
file, 2026-11-25).

## 3. Design

### 3.1 Details

`Details.resistor` gains `pot: PotInfo?`: `struct PotInfo { type: String; taper: String; turns:
Double; gangs: Int; a: String; w: String; b: String }` (first gang's pins), built from
`PartResistor` when `wiper_count > 0`. Every existing pattern match on `.resistor` gains the new
associated value (`_`).

### 3.2 Symbol and layout

- `PartSymbol.potentiometer` (after the last case).
- `symbol(for:)`: a `PART_RESISTOR` part with `pot` set, `gangs == 1` and all three wiper pins in
  its pins → `.potentiometer`; any other pot → `.block`.
- `ChipLayout.potentiometer(pins, pot)`: `a` left and `b` right at `diodeCentreY`, `w` at the
  bottom centre (the crystal layout with the pot's names); other pins (`nc` mounting tabs) are not
  drawn, as the inductor layout hides `NC` pads.
- `PotentiometerSymbolView` (new file, from `ResistorSymbolView`): the zig-zag, the wiper lead from
  the bottom pin up to an arrow head touching the zig-zag; for `trimmer`, the lead ends in a short
  bar perpendicular to it (IEC 60617 preset mark) instead of the arrow head. `paint(_:chip:…)` for
  `SchematicExportScene`.
- `canRotate`, `SchematicCanvasView`'s and `SchematicExportScene`'s switches, and
  `ReferenceLabel`'s three switches gain `.potentiometer` next to `.resistor`.

### 3.3 Facts and names

`PartFacts` rows per § 1; `kindName` per pot type; the array name (:481) skips pots.

### 3.4 Reference prefix

`ReferenceCategory.potentiometer` (raw value `potentiometer`, after `socket`), title
"Potentiometer", default prefix `RV`; `of` returns it for a `PART_RESISTOR` part with `pot` set,
before the `.resistor` case. Saved Settings without the new key fall back to the default (the
existing behavior for any category missing from the stored map).

### 3.5 Part Editor and exports

- `ResistorDraft`: regenerate with `python3 scripts/part-editor-schema.py . resistor` (E's keys are
  in `resistor.c`), then keep the hand edits: `wipers` a list of three `.pin` fields; `pot` and
  `taper` `.choice` fields; `turns` `.number`. `PartKindKeysTests` (drift) passes.
- `KiCadSchematicWriter.bodyBox` and `EasyEDAProSchematicWriter`'s small-symbol case list gain
  `.potentiometer`.

### 3.6 Fixture and tests

- A User Library fixture file in the test bundle, `PotFixture.json` (kind `resistor`): `POTFIX-1T`
  (one gang, `trimmer`, 25 turns, 10 kΩ), `POTFIX-1R` (one gang, `rotary`, `log`, 100 kΩ),
  `POTFIX-2R` (two gangs, `rotary`).
- `PotentiometerTests.swift` (new): symbol choice for the three parts and for a fixed resistor;
  layout slots (`a` left, `b` right, `w` bottom); fact rows and kind names; the `RV` prefix and
  numbering of two placed pots (`RV1`, `RV2`) beside a resistor (`R1`); a KiCad export of a pot
  has the small body box.
- `ResistorTests` and `PullResistorTests` run unchanged.

## Decisions

- Author: **the wiper at the bottom centre, as the crystal's GND**: an existing 3-pin layout keeps
  rotation, labels and exports working with no new geometry rules.
- Author: **a trimmer gets the preset mark, the others the arrow**: the two standard pot symbols,
  and the only visible difference between a set-and-forget trimmer and a user control.
- Author: **`RV` for every pot type**: IEEE 315's prefix for a variable resistor; `R` stays for
  fixed resistors.
- Author: **two-gang pots are blocks**, as resistor arrays are (plan-34-G): their six pins have no
  standard single-symbol drawing that fits the 2-terminal box.
