# SNx4HC00 quadruple 2-input NAND gates

## Description

Four independent 2-input NAND gates. Each gate performs Y = !{A · B} in
positive logic. Inputs are buffered standard CMOS inputs; outputs are
balanced push-pull outputs that can drive up to 10 LSTTL loads.
SN74HC00 is specified from –40 °C to 85 °C, SN54HC00 from –55 °C to
125 °C.

## Application information

Inputs: standard CMOS. Input signals must cross V~IL~(max) and V~IH~(min)
within the transition times in the
[recommended operating conditions](#recommended-operating-conditions);
slow edges raise supply current and can cause oscillation. Never leave
an input floating: tie unused inputs to V~CC~ or GND, or use a pull
resistor (10 kΩ is typical) for an input that is not always driven.

```figure ref=clamp-diodes caption="Clamp diodes on each input and output"
```

Outputs: balanced push-pull; they can source and sink similar currents.
Leave unused outputs open, never tie them to V~CC~ or GND, and never tie
together outputs that can be in opposite states. Two gates with the same
inputs may be paralleled for more drive. Keep the load at or below
50 pF and the resistive load above V~CC~ / I~O~(max).

Power: bypass V~CC~ with 0.1 µF placed close to the pin (0.1 µF and 1 µF
in parallel are common).

Typical use: two gates form an active-low S-R latch. In the source's
example a tamper switch drives !{S}; Q goes high and stays high until the
system controller pulses !{R} low.
