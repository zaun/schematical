# AT28C256 256-Kbit (32,768 × 8) paged parallel EEPROM

## Description

A 32,768 × 8 paged parallel EEPROM with a 64-byte page buffer,
read like a static RAM: 150 ns access time, 50 mA active and 200 µA
CMOS standby current, single 5 V ± 10 % supply, CMOS- and
TTL-compatible inputs and outputs, JEDEC byte-wide pinout, –40 °C to
85 °C.

A write latches the address and 1 to 64 bytes, then programs them with
an internal timer while the bus is free; !{DATA} polling on I/O7 or the
toggle bit on I/O6 report the end of the write. Writes are protected
in hardware (V~CC~ sense, power-on delay, noise filter) and, optionally,
by a software data protection (SDP) command sequence. An extra 64 bytes
hold device identification.

Endurance: 10,000 cycles (AT28C256, AT28C256F) or 100,000 cycles
(AT28C256E). Data retention: 10 years. Page write cycle time: 10 ms
maximum, 3 ms for AT28C256F.

## Functional description

Block diagram: the address inputs drive X and Y decoders into the cell
matrix (with the 64-byte identification row); data passes through the
data latch and the I/O buffers, under the !{OE}, !{CE} and !{WE} logic.

**Read.** With !{CE} and !{OE} low and !{WE} high, the addressed byte is
driven on I/O0–I/O7. The outputs are high impedance when !{CE} or !{OE}
is high.

**Byte write.** A low pulse on !{WE} or !{CE}, with the other low and
!{OE} high, starts a write. The address is latched on the falling edge
of !{CE} or !{WE}, whichever is last; the data on the first rising edge
of either. The write then times itself to completion (t~WC~); a read
during t~WC~ is a polling read.

**Page write.** Starts like a byte write; up to 63 more bytes may
follow, each within t~BLC~ (150 µs) of the one before. When t~BLC~ runs
out, the part stops accepting data and starts programming. All bytes of
a page share A6–A14, which must not change at any falling edge of
!{WE} during the page; A0–A5 select the bytes, in any order, and a byte
may be reloaded. Only bytes that were loaded are written.

**!{DATA} polling.** During a write cycle, reading the last byte written
returns the complement of its bit 7 on I/O7. When the write is done,
true data appears on all outputs and the next write may start.

**Toggle bit.** During a write cycle, successive reads toggle I/O6
between 1 and 0. It stops toggling when the write is done.

**Hardware data protection.** Writes are inhibited while V~CC~ is
below 3.8 V (typical), for 5 ms (typical) after V~CC~ reaches 3.8 V,
while !{OE} is low, !{CE} high or !{WE} high, and for pulses under 15 ns
(typical) on !{WE} or !{CE}.

**Software data protection (SDP).** Shipped disabled. The enable
sequence below protects the whole array after t~WC~, through power
cycles. A protected part still accepts a byte or page write that is
preceded by the same 3-byte sequence. A write without the sequence
starts the internal timer but writes nothing; reads during t~WC~ are
then polling reads. The command bytes are not written to the array, and
the command addresses can hold data like any other.

**Device identification.** With A9 at 12 V ± 0.5 V, addresses 7FC0h–7FFFh
read and write an extra 64 bytes, like the main array.

**Chip erase.** The whole array can be erased with a 6-byte software
code (Microchip application note "Software Chip Erase"), or with the
high-voltage sequence in the timing diagrams.

## Conversion notes

- Source pages 4–20 and 29 (ordering) converted; package marking,
  package drawings (21–26) and Microchip boilerplate (28–32) dropped.
- The source's operating range gives the supply as 5 V ± 10 %; the
  catalog's 4.5–5.5 V matches.
- Derived: 4.5 and 5.5 V (V~CC~, from "5V ± 10%", p.7); 11.5 and
  12.5 V (V~H~, from "VH = 12.0 V ± 0.5V", p.15).
- The SDP enable/disable flowcharts (6.11, 6.12) became one table. The
  source's note 2 of the disable flowchart repeats note 3 ("deactivated");
  the table keeps the meaning.
- Source issues:
  - Source error, corrected: the !{DATA} polling diagram labels its
    address bus "A0-A16"; this part has A0–A14.
- Curves digitized from Figures 5-1 to 5-3 (about 2 % of full scale).
- Block diagram (3.1) described in one sentence instead of drawn.
