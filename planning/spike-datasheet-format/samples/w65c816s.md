# W65C816S 8/16-bit microprocessor

## Description

A fully static CMOS microprocessor with a 16-bit internal architecture,
an 8-bit data bus and a 24-bit (16 MB) address space: A0–A15 carry the
low 16 address bits and D0–D7 carry the bank address (A16–A23) during
the first half of each cycle. The accumulator, ALU, X and Y index
registers and stack pointer are 16 bits wide; a 16-bit direct register
relocates the 6502's zero page, and program bank and data bank registers
give segmented or linear 24-bit addressing. 92 instructions, 256
opcodes, 24 addressing modes.

After reset it runs in emulation mode, software compatible with the
W65C02S (except the BBRx, BBSx, RMBx and SMBx bit instructions, which
the W65C816S lacks). The XCE instruction switches to native mode, where
the M and X status bits select 8- or 16-bit accumulator/memory and index
registers.

Beyond the 6502 bus, it has an !{ABORTB} input that ends the current
instruction without changing registers (for virtual memory), VDA and
VPA outputs that qualify data and program cycles (cache, DMA cycle
stealing), a vector-pull output !{VPB}, memory lock !{MLB}, mode outputs
E and MX, and a bus enable BE. WAI and STP stop the processor for low
power (about 300 µA at 1 MHz). Supply 1.8 V to 5 V in five specified
ranges, 14 MHz at 5 V; –40 °C to 85 °C.

## Pin functions

```pins
A0, A1, A2, A3, A4, A5, A6, A7, A8, A9, A10, A11, A12, A13, A14, A15: Address bus, low 16 bits of the 24-bit address. High impedance while BE is low.
D0, D1, D2, D3, D4, D5, D6, D7: Data bus and bank address (BA0–BA7 = A16–A23): the bank address during the first half of each cycle (PHI2 low), data during the second half (PHI2 high). Two cycles move a 16-bit value. High impedance while BE is low.
ABORTB: Abort input, active low, pulse sensitive: a low pulse (or level) during a PHI2 cycle stops the current instruction from modifying registers; when it completes, an abort interrupt saves the aborted opcode's address and vectors through 00FFF8,9 (emulation) or 00FFE8,9 (native).
BE: Bus enable input, asynchronous. High: address buffers and RWB active, data/address buffers active in the first half of every cycle and the second half of write cycles. Low: these buffers are high impedance.
E: Emulation status output: the E flag (1 = emulation mode, 0 = native mode).
IRQB: Interrupt request input, active low, level sensitive. When the I flag is 0, starts an interrupt sequence after the current instruction; vector 00FFFE,F (emulation) or 00FFEE,F (native).
MLB: Memory lock output, active low: low during the last three or five cycles of ASL, DEC, INC, LSR, ROL, ROR, TRB and TSB on memory (depending on M), so bus arbitration of the next cycle can be deferred in multiprocessor systems.
MX: Memory/index status output, multiplexed: the M flag while PHI2 is low (valid at the PHI2 falling edge) and the X flag while PHI2 is high (valid at the rising edge).
NMIB: Non-maskable interrupt input, falling-edge sensitive: starts an interrupt sequence after the current instruction; vector 00FFFA,B (emulation) or 00FFEA,B (native).
PHI2: Phase 2 clock input. May be stopped in either state to keep the registers and save power (standby).
RDY: Ready, bidirectional, with an active pull-up (off while the pin drives low); wired-OR capable. Input low halts the processor in its current state; returning high resumes it after the next PHI2 falling edge. Driven low by WAI until an interrupt or reset.
RESB: Reset input, active low, with hysteresis and an internal pull-up, so an R-C circuit can drive it. It must be held low for at least two clock cycles after V~DD~ reaches operating voltage.
RWB: Read/write output: high = read, low = write (data on D0–D7 from the processor). High impedance while BE is low.
VDA: Valid data address output: high when the address bus holds a valid data address (with VPA, see the VDA/VPA function table).
VPA: Valid program address output: high when the address bus holds a valid program address.
VPB: Vector pull output, active low: low during the two cycles of an interrupt sequence that read the vector, so interrupts can be prioritized by modifying the vector address.
VDD: Positive supply
VSS: Ground (system logic ground)
NC: No connect
```

## Functional description

Block diagram: the address buffers (A0–A7, A8–A15) and the data
bus/bank address buffer (D0–D7, gated by BE) connect through transfer
switches to three internal 16-bit buses (internal address bus, internal
special bus, internal data bus) that link the X, Y, S, D, C (A and B)
and PC registers, the 16-bit ALU, the PBR and DBR, the status register
and the data latch/predecoder feeding the 8-bit instruction register;
the instruction decode, timing control, interrupt logic (ABORTB, IRQB,
NMIB, RESB, RDY) and clock generator (PHI2) drive the system control
outputs RWB, VPA, VDA, MLB, VPB, E and MX.

The processor has a register section, where instructions run as a
series of register transfers, and a control section that generates the
transfer signals.

- **Instruction register (IR).** The opcode is latched into the IR from
  the data bus in the opcode fetch cycle and decoded, with the timing
  and interrupt signals, into IR control signals.
- **Timing control unit (TCU).** Counts the cycles of each instruction:
  zeroed at each opcode fetch, advanced at the start of every cycle.
  Every register transfer is decoded from the IR and the TCU together.
- **ALU.** 16 bits wide. Computes data results (stored in memory or a
  register, updating C, N, V and Z) and the effective addresses of
  relative and indexed modes.

### Bus cycle

Each cycle starts at the PHI2 falling edge. While PHI2 is low the
processor drives the address on A0–A15 and the bank address on D0–D7;
while PHI2 is high D0–D7 carry data (read or write). An external
transparent latch, open while PHI2 is low, holds the bank address (see
[application information](#application-information)). The address bus
is valid whenever VDA or VPA is high, and in every write cycle. With
VDA and VPA both low the address (including page and bank) may be
invalid: this is the internal cycle in which only the low byte of an
indexed address has been added. That cycle is optional for reads with
8-bit index registers, and always present for stores, for all
instructions with 16-bit index registers, and for read-modify-write
instructions. VDA and VPA should qualify every memory cycle.

### Ready and wait

RDY low halts the processor in any cycle, including write cycles (the
NMOS 6502 ignores RDY during writes). While RDY is low the data bus
stays in the data transfer state (as with PHI2 high), so latch the bank
address on the rising edge of PHI2.

WAI pulls RDY low and enters a low-power wait. RESB, NMIB or IRQB ends
the wait and runs the interrupt handler. If the I flag is set, IRQB
instead resumes with the instruction after WAI, without the handler:
the fastest response to IRQB. !{ABORTB} aborts the WAI instruction but
does not restart the processor; an interrupt received after an abort
during WAI returns to the WAI instruction. The processor does not stop
at WAI if RDY is held high externally. STP does not affect RDY.

### Stop the clock

STP stops PHI2 to all internal circuits, held in the high state: the
data bus stays in the data transfer state and the bank address is not
multiplexed onto it. Only RESB restarts the processor: its falling edge
re-enables the clock. The external oscillator must be stable before
RESB goes high.

### Abort

!{ABORTB} should be low for no more than one cycle. If it is held low
during the abort interrupt sequence, the abort interrupt itself is
aborted (not recommended). The internal abort latch clears in the
second cycle of the abort interrupt. Registers are still modified when
!{ABORTB} arrives late:

- read-modify-write: the status register is modified if !{ABORTB} comes
  after the modify cycle;
- RTI: the status register is modified if !{ABORTB} comes after cycle 3;
- IRQB, NMIB, ABORTB, BRK and COP sequences: after cycle 2, PBR and DBR
  become 00 (emulation mode) or PBR becomes 00 (native mode).

The abort interrupt is meant for virtual memory systems; an
asynchronous !{ABORTB} may give these undesirable results.

### MX output

MX shows the M and X bits. REP, SEP and PLP may change them; MX is
invalid during the cycle after REP, SEP or PLP, which is the next
instruction's opcode fetch.

The 6502's registers are A, XL, YL, SL and PC (PCH:PCL). PBR is
changed only by RTI, RTL, JML, JSL and JMP absolute long (and cleared
by interrupts); it does not change when the PC wraps from FFFF, so code
may exceed 64 KB but a code segment can't cross a bank boundary.

N, V, Z and C report ALU results and are tested by the branches; D, I,
M and X are mode bits set by the program. N, V and Z are valid in
decimal mode. All register-to-register transfers carry 16 bits from the
source; the destination's size decides how many bits are stored and how
the flags are set. TCS, TSC, TCD and TDC always transfer 16 bits,
whatever M is. PHP and PLP are always 8-bit.

### Reset

```table id=reset-diagram caption="State after reset"
| Item | Value |
|---|---|
| D, DBR, PBR | 0000, 00, 00 |
| SH, XH, YH | 01, 00, 00 |
| SL, XL, YL, A, B | not initialized |
| P | M = 1, X = 1, D = 0, I = 1, E = 1; N, V, Z, C not initialized |
| E, MX, RWB, VPB | 1 |
| VDA, VPA | 0 |
```

RDY has no effect while RESB is low. When RESB goes high an interrupt
sequence (bus cycles 22a) starts: STP and WAI are cleared, RWB stays
high during the stack cycles, and PC is loaded from 00FFFC,D.

### Emulation and native modes

XCE exchanges C and E. Entering emulation mode sets M and X to 1, SH to
01 and XH and YH to 00; save these bytes before switching. SL, XL, YL, A
and B are not affected by a mode change. In emulation mode REP and SEP
can't change M and X. Every opcode works in both modes: JSL, RTL,
JMP al and JML are meant for native mode; PHK, PHB and PLB work in
emulation mode with banks forced to 00; MVN and MVP in emulation mode
can only move data within 0000–00FF of the source and destination
banks.

**Stack.** Native mode: anywhere in 000000–00FFFF, for stack, stack
relative and stack relative indirect indexed addressing. Emulation mode:
000100–0001FF, except that JSL, JSR (a,x), PEA, PEI, PER, PHD, PLD and
RTL run past this range when they access two or three bytes. In
emulation mode TCS doesn't load B into SH (01 is forced); in both modes
TSC copies all 16 bits of S into C, whatever M is.

**Direct page.** Direct, direct,X and direct,Y addresses always lie in
000000–00FFFF in native mode. In emulation mode:

- DL = 00, DH = 00: 000000–0000FF, except [d], [d],y and PEI, which
  run on from 0000FE or 0000FF into the stack page;
- DL = 00, DH ≠ 00: 00DH00–00DHFF, except [d], [d],y and PEI, which run
  on from 00DHFE or 00DHFF into the next page;
- DL ≠ 00: 000000–00FFFF.

**Absolute indexed.** Indexing from bank ZZ, page FF may reach bank
ZZ+1 (the W65C02S wraps to page 00 of the same 64 KB).

### Interrupts

An interrupt (IRQB, NMIB, ABORTB, BRK, COP) pushes PBR (native mode
only), PCH, PCL and P, sets I, clears D (binary mode) and clears PBR to
00; in emulation mode the old PBR is lost, and B in the pushed P tells
BRK (1) from IRQB (0). Vectors are read from bank 0 with !{VPB} low
(see [memory map](#memory-map)). RTI pulls P, PC, and PBR in native
mode; run it in the mode that took the interrupt. Interrupts do not
change DBR (only an abort after cycle 2 does, above).

Priority when several arrive together: RESB (highest), ABORTB, NMIB,
IRQB (lowest).

!{IRQB} is level sensitive: it interrupts again if the source is not
cleared, and not at all if the source clears before recognition.
!{NMIB} is edge sensitive: a new falling edge interrupts even while a
previous interrupt is served; a held low level interrupts once.

BRK and COP are 2-byte instructions: the second byte is a signature,
skipped by the processor; RTI returns past it. COP signatures 00–7F are
user-defined, 80–FF reserved by WDC. WDM (42) performs no operation and
is reserved for future processors.

M24 is a 3-byte pointer (low, high, bank). Direct, direct,X and
direct,Y addresses always lie in bank 0, as do stack addresses and the
vectors. JMP (a) and JML (a) read their pointer from bank 0; JMP (a,x)
and JSR (a,x) read theirs from the program bank. Block move: byte 2 of
the instruction is the destination bank (also loaded into DBR), byte 3
the source bank; C holds the byte count minus one. Each byte moved
increments (MVN) or decrements (MVP) X and Y and decrements C; when C
passes 0 the instruction ends and PC = PC + 3. MVP is used when the
destination start address is above the source start address.

### Instruction summary

One row per opcode. Flags: a letter = affected, `.` = unchanged, `0`/`1`
= cleared/set. Bytes and cycles assume M = 1, X = 1, DL = 0, no page
crossing, branch not taken, emulation mode for BRK and COP and native
mode for RTI. Adders:

- **m**: +1 cycle if M = 0; on immediate also +1 byte. **m2**: +2 cycles
  if M = 0 (read-modify-write).
- **x**: +1 cycle if X = 0; on immediate also +1 byte.
- **d**: +1 cycle if DL ≠ 0.
- **p**: +1 cycle if indexing crosses a page boundary, or X = 0.
- **b**: +1 cycle if the branch is taken; +1 more if taken across a page
  boundary in emulation mode.
- **n**: +1 cycle in native mode. **e**: –1 cycle in emulation mode.
- REP and SEP always take 3 cycles.

Block moves: cycles 1–7 repeat for every byte, each time with X and Y
one further on (X+1, Y+1… for MVN; X–1, Y–1… for MVP), refetching the
opcode at PBR,PC; after the last byte (C = 0 before the move) cycle 1
fetches the next opcode at PBR,PC+3. STP restart: cycles 1c, 1b, 1a run
while RESB is low, then the reset interrupt sequence (22a) begins.

### Assembler syntax

WDC's recommended assembler syntax. Directives are not standardized. A
blank line, or one starting with `;` or `*`, is a comment. A source line
has four fields: label (from column 1; starts with a letter, then
letters or digits; at least 6 significant characters; lower case equals
upper case), operation code (a three-letter mnemonic, not before column
2, or one space after the label; case-insensitive when labels are),
operand, and comment (at least one space after the opcode or operand).
Duplicate mnemonics are resolved by the operand.

```table id=aliases caption="Alternate mnemonics an assembler may accept"
| WDC standard | Alias |
|---|---|
| BCC | BLT |
| BCS | BGE |
| CMP A | CMA |
| DEC A | DEA |
| INC A | INA |
| JSL | JSR (long address forced) |
| JML | JMP (long addressing forced) |
| TCD | TAD |
| TCS | TAS |
| TDC | TDA |
| TSC | TSA |
| XBA | SWA |
```

WDC's assembler accepts JMP [a] for JML (a) (DC), JMP al and JML a for
absolute long (5C, also JML $001234), JMP a for absolute (4C, also
JMP $001234), and assembles JMP ($123456) as JMP ($3456) (6C).

The operand field allows labels, decimal constants and hexadecimal
constants (`$` prefix), addition and subtraction, and at least 24-bit
signed or unsigned arithmetic. In the formats below, d is a value below
$100, a below $10000, al a 24-bit value, EXT a label not yet located
(assumed 2 bytes), r and rl 8- and 16-bit signed displacements. The
prefixes `<`, `|` (or `!`) and `>` force direct (1 byte), absolute
(2 bytes) and long (3 bytes) addressing; an unforced address is 2 bytes
unless context decides; a forced address is truncated without error
(LDA $0203 = LDA |$010203); a short address where the instruction has
no short mode is zero-extended. Immediate size is not set by the
operand but by directives (separately for accumulator and index).
Brackets mark a long indirect pointer, parentheses a 16-bit one.

## Application information

Bank address latch: PHI2, inverted, drives the enable of a 74x573 (or
'373) transparent latch whose D inputs take D0–D7 and whose Q outputs
(output enable tied low) are BA0–BA7 (A16–A23), so the latch is open
while PHI2 is low; the same inverted PHI2 drives the active-low enable
of a 74x245 transceiver between D0–D7 (B side) and the system data bus
(A side), with RWB on DIR, so the data bus connects only while PHI2 is
high. PHI2 also clocks the rest of the system.
